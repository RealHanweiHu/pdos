# 自行车打气筒（`bicycle-pump`）品类种子资料

> **草稿 v0.2，C/D 业务口径已确认；参数与法规适用待专业确认** · 2026-10-08 · 来源性质 `ai_draft` · 机读版 `bicycle-pump.json` 与本文内容一致，以 json 为准导入。来源编号见 `sources.md`。

## 1. 品类边界

**定义**：以自行车（含电助力自行车）轮胎打气为主要用途的打气产品，包含锂电电动、手动（落地式/便携式）和 CO₂ 充气器；按形态、用途与工况分组。汽车/自行车等多功能泵归汽车品类。

**已确认规则**：按用途划界，供电/结构/产品形态在品类内分组；汽车/自行车等多功能泵统一归汽车品类，按市场对标；分类不以当前我方自研范围为边界。 决策记录见 [C/D 确认记录](README.md#cd-confirmed)。

| 包含 | 依据 |
|---|---|
| 锂电电动迷你打气筒（直插或短软管） | 自行车打气用途；我方当前自研范围单独记录 |
| 电助力自行车（e-bike）轮胎 | 属自行车轮胎；Presta / Schrader / Dunlop 均可能出现 |
| 公路、砾石、山地、城市通勤车轮胎 | 同属自行车用途；现有锂电草稿按两类标准胎研究，其他形态和具体条件待专业确认 |
| 球类、泳圈等附带场景 | 只作为 valve_compatibility 取值记录 |
| 手动打气筒（落地式、迷你手持） | 用户确认按用途纳入；手动形态单独比较参数与工况 |
| CO₂ 充气器 | 用户确认按用途纳入；气瓶/耗材与专用参数、工况及法规待专业确认 |
| 电动滑板车/平衡车轮胎（兼用场景） | 仅记录兼用场景，工况单列；多功能汽车泵仍按汽车品类对标 |

| 不包含 | 依据 |
|---|---|
| 汽车充气泵与汽车/自行车等多功能泵 | 归 auto-tire-inflator，按市场对标 |
| 摩托车轮胎 | 归 auto-tire-inflator 次要场景 |
| 桨板 / 充气床泵 | 低压大流量、专用气门，建议另立品类 |
| Tubeless 坐胎专用爆冲气罐/设备 | 用途为瞬间大流量坐胎，专用字典待另行研究；普通落地式手动打气筒按打气用途纳入本品类 |

**判断依据**（场景参考；具体形态按下述覆盖范围分别验证）：

| 维度 | 汽车充气泵 | 自行车打气筒 | 桨板/充气产品泵（不在本次范围） |
|---|---|---|---|
| 主要使用场景 | 车边补气、应急 | 骑行前打气、路上补胎后充气 | 水上/露营充气，低压大容积 |
| 目标压力量级 | 几十 psi（以车辆铭牌为准） | 公路胎可到 100 psi 以上，山地胎几十 psi | 十几 psi 量级 |
| 主要气门 | Schrader(AV) | Presta(SV) 为主，Schrader、Dunlop 并存 | Halkey-Roberts 等专用阀 |
| 标准测试工况 | 205/55 R16，0→36 / 26→36 psi | 700×25C 0→100 psi；29×2.25 0→30 psi | 另定 |
| 关键性能 | 补气时间、停机准确、续航次数 | 高压可达性、重量体积、Presta 连接 | 大流量、充满时间 |
| 重量重要程度 | 中 | 高 | 低–中 |

注：压力量级为常识性描述，实际以车辆铭牌和轮胎侧壁标注为准（Schwalbe 官方说明自行车胎压力见侧壁），待专家确认。 本表为已有充气场景参考，不改变已确认的按用途归类；自行车手动/CO₂、组合机和兼用场景另列专用条件。

| 电动滑板车 / 平衡车轮胎 | 作为兼用场景，工况单列；不单独建品类 | 用户 Q5 及最终确认 | 用户已确认 |
| 汽车/自行车等多功能泵 | 归汽车品类，按市场对标 | 用户 Q4 | 用户已确认 |

## 2. 规格字典（全部参数 version = 1）

**覆盖范围**：本版 30 个参数及测试项只覆盖锂电电动形态草稿。手动、CO₂ 已纳入品类，但专用字典与测试骨架待补；不得把电动泵 required 参数和充满/自动停机工况直接套用于两类新增形态。

- **基线条件 B0**：环境 23±2 °C；按说明书充满后静置 ≥1 h。表中“B0”在 json 中已展开为完整文字。
- **TIRE_ROAD**：测试轮胎 700×25C（ISO 5775-1 标记 25-622）开口胎 + 丁基内胎，Presta 气门（可拆芯），装于匹配轮辋、不承载。
- **TIRE_MTB**：测试轮胎 29×2.25（ISO 5775-1 标记 57-622）开口胎 + 丁基内胎，Presta 气门，装于匹配轮辋、不承载。
- **压力单位**：主单位 psi（表压；1 bar = 14.504 psi = 100 kPa；1 psi = 6.895 kPa；1 kgf/cm² = 98.07 kPa = 14.22 psi；系数据 NIST SP 811）。不同单位、版本或工况的数值不当作同口径比较。
- **方向**：越大越好 / 越小越好 / 目标区间 / 无方向（对应库内 higher / lower / target / neutral）。**权重**为对标权重建议。**状态**：AI 起草 / 待专家（有待确认点）。

## 5. 用户与场景骨架

| 典型用户 | 说明 |
|---|---|
| 公路车骑行者 | Presta、高压、重量体积敏感 |
| 山地 / 越野骑行者 | 低压精度、耐用防水 |
| 通勤 / 城市车、电助力车用户 | Schrader、Dunlop 较常见（待研究） |
| 长途骑行 / 骑行旅行者 | 续航、可靠性 |
| B2B：自行车配件品牌、电商品牌、车店与俱乐部（OEM/ODM） | 按规格书采购 |

- **使用场景**：骑行前在家打气（替代落地打气筒）；路上爆胎补胎/换内胎后充到可骑行压力；山地骑行中按路况微调胎压；赛事与骑行活动保障（多车多次）。
- **JTBD**：“骑行途中爆胎修补后，用一只能随身带的小泵把胎充到可骑行压力”；“出门前快速、准确地把胎压打到想要的值，不用费力”。
- **购买标准（重要度均为“待研究”）**：重量与体积、能否到达公路胎压力及所需时间、Presta 连接是否可靠、压力精度、续航次数、防水、价格、品牌与评价。
- 首批知识覆盖：欧盟、美国、加拿大、日本、澳大利亚、中国大陆；每份提案明确实际销售市场和客户/渠道；购买排序、细分占比与渠道差异仍待研究。

## 7. 待专家确认清单

1. `max_pressure`：密封容器容积 0.1 L 是否合适
2. `fill_time_road`：目标压力 100 psi 还是 80 psi；胎宽 25C 还是 28C
3. `fill_time_mtb`：山地车常用无内胎，测试用内胎是否可接受
4. `pressure_accuracy`：测试点组合
5. `valve_core_retention`：循环次数与判据
6. `endurance_tires`：0→80 psi 还是 60→90 psi 补气
7. `noise_level`：测量距离与负载
8. `display_units`：强光可读性评价方法
9. `operating_temp`：是否需要低温验证
10. `continuous_run_time`：背压 100 psi 是否合适
11. `surface_temp`：判据采用哪个安全标准
12. `drop_robustness`：跌落高度、次数；是否加振动试验
13. 边界：带自行车灯功能的泵（待专家确认）
