# S4 制造交付接续合同

本合同细化完整目标架构 v1.1 §03.8、§04.3/9–14、§08.11、§09.2 路径 E、§09.6 及附录 A 的相关操作，依据设计确认稿 P21 接续独立建设。S3 的真实合成配置实施、本人完成与新轮复测/回链已有固定候选 `745323e` 及对应证据；S1/S2/S3 正式验收仍未完成，S3 一天观察要求保留，性能验收按 P13 暂缓。

## 首个业务闭环

在项目制造准备与实际 BuildLot 上，具名人员固定本轮制造基线及其用途、工程/制造配置、工艺/工序、SOP、控制计划、工具设备、人员/线体与包装标签要求，随后创建关联实际 Build 的 PilotRun；登记本轮实际投入、产出、返工/报废/待判等原文事实，回读首次通过率与最终合格率，并将具体异常关联已有 Issue/CAPA。原记录和修正版本均可回查。

现有制造准备 T1 草稿账本保留。正式基线发布使用独立具名 T2 记录，固定已选择的真实内容、适用范围与来源，保留实际批准人、当前专业授权、共同确认消费及完整回执。发布对象与原 draft 内容分别保留；后续内容续版不改已固定版本，引用漂移按 v1.1 §08.11 和实际用途规则提示及判定。基线发布、实际资产验收/资格、本轮准备度以及最终制造放行各自提供真实事实；任何未知均明确呈现，不从标题、存在性或已保存标签推定合格。

## 领域与执行边界

PilotRun 是 Build 的制造扩展，固定 BuildLot、样件/批次及实际产品配置、制造基线、用途和本轮数量范围；统计事实还固定产线、人员、物料、工具设备、实际参数、首件、原始时间与来源。读取真实领域 owner，缺失接线或材料保留具体缺项，不能以空集合成功代替。对变更影响范围消费实际批准计划、实施输出和对应复验资料；措施完成和单个 Run 通过各自保留原义。最终放行依其实际规则处理适用的阻塞与未知，不新增全部 Issue 关闭的通用前置。

命令沿用共同 T1/T2 预备、本人确认、版本/权限/来源重核、幂等及原子尾部；只读来源和聚合不授予业务写权。锁序、实际 Session/UOW、当前对象、取消及来源撤回继续由宿主执行。共同消费、不可变领域记录、Current、Receipt/Audit/Outbox 及必需的验证意图在同一事务完成；结果未知保留原请求并先核对回执。

## 统计、整改与后续交付

首次通过率和最终合格率分别保留固定分母、抽样范围及条件。合格、报废、待判和返工中等终态互斥，修正仍绑定同一批实际成员；相容批次按实际数量加权，百分比不直接平均。不充分样本只显示当前事实和未知，不以短期良率推断长期能力。具体异常通过真实原文和精确配置/数量/用途关联现有问题和变更领域。

后续发布包固定定义、双配置、验证、遗留/例外、数量/批次/产线/地区与批准；工程和制造分别决定，接收方确认自己的范围。外部接口未接时建设受控人工证据路径，分别记录 manifest、编号/版本映射、发送意图、接收与实际生效。真实外发、生产及部署继续等待对应明确授权；本地合成记录不冒充外部实际接收或生产启用。

## 验证与当前覆盖

按可办理的完整闭环统一做实际 API/独立 `pdos_test`/页面验证，权限、事务写入、版本与统计规则做必要受影响检查；迁移由主会话核对当时真实 head 后单调分配。当前只是施工合同：PilotRun 的实际持久、公共注册、API/UI、放行和接收/生效均未据此宣称完成。当前能力、证据和剩余工作仅在唯一清单原位更新。
