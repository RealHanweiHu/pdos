# S2 项目办理接续合同

依据为[完整目标架构 v1.1](2026-10-08-pdos-complete-target-architecture-v1.1.md) §02.7、§08、§09 与附录 A/B，以及[确认稿 P13](2026-10-08-pdos-next-design-confirmation.md#p13-暂缓性能验收并提前恢复-s2用户-2026-10-17)。用户已授权先恢复 S2，S1 保持未验收，性能验收暂缓。本文只细化 S2；历史波次合同继续作为只读实现参考，不恢复其旧范围根、数量上限或阶段出口。

本闭环接续 G0 产出的真实项目，完成当前项目的配置/Build、用途批准、实际产出/样件、验证准备、品质交接、测试与结果入口。品类仍是权限范围根，项目只收窄办理上下文；型号共用配置和历史的普通读取权限继续由领域服务判定。

## 本批行为

- 项目入口将实际项目 ID 传入八个 S2 面板。Build 列表在服务器核对项目所属型号及当前受众后过滤；合法空项目返回空列表，缺失、其他型号或不可见项目拒绝。无项目参数时保留原型号总览。
- 八个面板的挂载身份、本机草稿、选择与原请求均按本人/型号/项目区分。返回原项目可恢复原请求；不从型号旧草稿自动迁入。Build 新建固定当前项目，恢复不匹配项目的 Build 创建请求时明确拒绝提交。
- 测试结果先读取本项目可见轮次，再按所选 Build 读取详情。旧选择不属于本项目时不深读其他轮次；读取失败不回退到全部项目，不自动提交或重发。
- 写入沿用受控命令、T1 完整预览确认、T2 具名专业决定、CAS、回执及原请求恢复。服务器继续核对实际项目/配置、来源和专业事实；本批不增加任何 AI 写权或真实资格。

## 验证与阶段余项

本批验证同型号双项目筛选、合法空结果、权限撤销、原型号总览兼容、前端项目切换与草稿恢复，以及结果读取失败；真实合成项目经 G0 创建，Build 经现有领域命令保存。合成前置不代表真实制造或专业资格。

S2 阶段仍须集中贯通附录 B 的 AT-07/08（计划与实际、多批配置）、AT-11/12（样件冲突、试模前策划）、AT-13/14/15（齐套/交接时钟、部分接收、部分返回）及相关恢复路径。本批入口修复或已有局部检查不能单独替代这些场景的最终联验。进度与证据只登记于[唯一清单](../../tasks/ai-native-integrated-todo.md#current-queue)。

无新增迁移，不执行真实模型、业务资料出站或生产操作，不启动 S3–S4。
