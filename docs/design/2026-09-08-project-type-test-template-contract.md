## 1. 模板与报告各自的作用

| 对象 | 决定什么 | 边界 |
|---|---|---|
| 项目类型 | 测试模板的适用范围，如锂电汽车泵、锂电自行车泵、帐篷泵 | 类型可扩展，以上不是封闭枚举；D14-04 已由用户明确确认为锂电自行车泵 |
| 版本化测试模板 | 适用条件、测试项稳定标识、必测/选测、方法/标准引用、单位、证据要求 | 各类型可有共用项及专属项；不能从单份报告反推完整必测集 |
| 项目测试计划 | 引用已选择的模板版本，结合项目规格记录增减项、理由、确认人和时间 | 项目差异不反向覆盖公共模板；换版应显式比较变化，不改历史测试依据 |
| 报告解析映射 | 工作表/区域/字段如何转换为候选记录 | 解决文件布局，不决定业务必测项；相同列名不代表相同测试政策 |
| 测试报告 | 实际提供的观测、结论和证据 | 只抽取实际内容；额外项先列候选，未知项不能静默丢失或直接变必测项 |

项目选择模板后才可计算缺项：将报告确认记录与该版本中适用的必测项比对。没有选定模板时显示“尚未选择测试模板，无法判断必测覆盖”，不默认全量必测、覆盖 100% 或缺项为零。

## 2. 结果与适用性分开保存

- **未测试**：没有完成记录，不能由空白自动改为合格。
- **不适用**：由项目规格/适用条件及用户确认支持，保留理由；不能因为报告没出现该项就推定不适用。必测规则的例外须按既有政策处理，不能绕 Gate。
- **参考**：保留参考值与原文，不能强制归一为合格/不合格。
- **合格 / 不合格**：保留报告原结论、实际结果及判定依据；缺证据时另标待核对，不用结论覆盖缺项。

这些是业务语义合同，不要求把全部词直接加进 Test Run 生命周期枚举；实现应明确区分适用性、执行状态、报告结论和证据完整性。型号码不等于唯一 SN，上传目标项目不等于原报告项目。

## 7. D14-04 模板配置与覆盖首版（2026-09-08，本地候选）

本节是 §6 之后的增量，前文“尚未创建数据库模板或发布配置”描述初次确认时的状态。当前已生成 [自行车泵模板 v1](../../server/app/domain/test_templates/lithium-bicycle-pump-v1.json)、[D14-04 选择参数](../../assets/pilots/d14-04-test-template-v1.json) 与 [待测清单](../pilots/D14-04-test-plan-v1.md)。原件只用于提取测试项/方法/标准/来源，不包含其他项目的实测结果。

### 存储和接口

- 本地迁移 `0057_test_template_snapshot`：计划新增 `template_snapshot`，用例新增 `template_item_key`，租户/计划内稳定项标识唯一。旧计划为空时不强行绑定模板；有快照或稳定项绑定时禁止直接降级，以防丢失历史依据。
- 模板目录为受版本控制的只读配置；用户选择后把完整内容、digest、产品类型、版本、不适用理由、确认人和时间保存到计划快照。后续目录调整不回写旧计划。没有新增租户模型调用或 Agent 写权限。
- `GET /npi/test-templates` 返回允许选择的模板及当前项目 EVT/DVT/PVT 阶段；`POST /npi/test-plans` 可带 `template`；已有空白计划可 `POST /npi/test-plans/{id}/template`。权限沿用工作项编辑权限，项目与租户仍从登录上下文校验。
- 已有用例、已绑定模板或已完成的计划拒绝再次绑定；换版另建计划，保留原计划/结果。未知版本、产品类型不符、重复/未知不适用项、空理由、全部必测项均不适用会拒绝。确认时间与操作人由服务端生成，不接受客户端伪造。
- 模板适用项生成待测用例；不适用项留在快照中，不伪造 waived 测试执行、样机、时间或结果。保存与实例化在同一事务留事件和审计。用例显示按模板顺序。

### 统计合同

- 未配置模板：覆盖数/百分比为 null，界面明确“无法判断必测覆盖”，不显示 0 缺项或 100%。
- 分母：所选快照中 `required=true` 且适用的项。D14-04 为 29；照明保留不适用理由，不进分母。
- 分子：该稳定项所绑用例的最新 confirmed Run 有证据文档、结论为 passed/failed，且用例当前状态一致、用例没有比该 Run 更新的决策。草稿、新的无证据结果、直接改状态或旧证据不计入。
- 失败可以计入“有结果证据”，但不能计入“通过”；另列失败与待补项。参考值、不适用、空白不能通过模型映射变成 passed。报告包含模板已排除的照明项，即使写 PASS，也以 `template_not_applicable` 跳过并保留理由。
- 这是测试项结果证据覆盖，不是样机数量覆盖，不表示全部样机通过，不直接改变既有 Gate 硬闸策略。
