> 日期：2026-09-08。按用户“明确原版生产出口”整理既有要求。执行依据仍为 [preview 执行计划](2026-08-09-preview-execution-plan.md)，本文不新增产品范围、不批准生产操作、不确认任何 Exit 通过。本次仅核对仓库证据，未连接生产。

## 1. 原版范围与完成定义

“原版”指 preview 规格对应的 PDOS Sprint 0～5，以及已批准的账户管理、历史项目读取、首用体验修复和 MiniMax M3 启用收口。旧 CEHub 是待迁移并转只读归档的系统。

**原版生产出口 = 获批版本的工程与部署门禁通过 + 生产 AI 可用 + S5-1 真实钉钉验收通过 + S5-2～S5-4 验收成立 + 全量切换与只读退役通过 + 用户正式确认。**

S0～S4 的既有人工出口继续有效；本轮对最终候选做完整回归和受影响路径复验，不重新设计已批准能力。V0 冻结、V1 真实试点和 Phase Exit 各自裁决；它们不自动加入原版的功能验收范围，也不能替代原版的生产证据。D14-04 联合推进的安排继续按 [联合验收合同 §8](2026-09-08-v0-v1-acceptance-and-pilot-contract.md#8-sprint-5-与-d14-04-联合验收顺序2026-09-08-决定) 执行。

## 4. 执行与授权边界

1. **本地准备**：整理原版候选、变更清单、迁移差异、完整回归和回滚资料，汇总已有证据及缺口。D14-04 资料缺失只阻塞依赖它的工作，独立准备继续进行。
2. **生产只读预检**：用明确的 release、tenant、project 范围提交具体操作清单，经授权后核对线上版本、模型资格、钉钉 readiness、旧库全量清单和已迁移数据。只读授权不包含部署、身份绑定或外发。
3. **部署与运行补验**：版本/迁移/备份/回滚方案可审阅后，申请该次部署；生产 AI 调用与钉钉 Stage B/C 按具体范围分别授权并留证。原有合成评测批准不扩大为生产业务数据出站授权。
4. **切换窗口**：按 [切换手册](../runbooks/sprint-5-cutover-and-retirement.md) 分步取得写冻结、最终 dry-run、apply、主入口和只读退役的授权；已完成的同范围证据先核对，不能用旧批准覆盖新指纹、新 release 或新操作。
5. **出口确认**：完成 P1～P5 后提交实际结果与残余事项，由用户确认 P6；再更新 S5-1 与 canonical Sprint 5 完成状态。V0/V1 的证据和签核单独记录。

`delivery=false` 是当前保护状态。Stage C 只在测试群、收件人、审批/卡片模板和发送范围明确且获批准后启用；验收记录须写明测试后的开关状态与持续外发范围。切换手册默认保持 false；若最终仍禁用常态通知，须由用户明确确认该运行方式及影响，不能宣称通知已常态上线。补验选择、文档整理和 Exit 确认均不自动授权扩大外发。
