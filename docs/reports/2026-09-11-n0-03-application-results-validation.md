# N0-03 主动请求结构化结果持久化验证

2026-09-11，本地候选 0085。Chat、风险建议、测试计划和报告映射通过实际 Gateway 持久化成功结构化结果，为后续接续保留可核验的输出。当前仅支持有效持有者复用，N0-03 仍为部分完成。[运行说明](../runbooks/application-result-checkpoints.md)。

## 本次实现

- 新增不可变 application_result_checkpoints：唯一 tenant/run/model_call_id，四个外键关联真实 Observation、最终尝试 Manifest、原 Owner lease 与同租户 trace。原始供应商响应不落入结果表；业务 Finding 和审批状态不由该表替代。
- 已结算模型 trace 保留；调用 session 关闭与结构化结果保存使用同一事务。提交前中断不留下伪完成结果，提交后中断保留原结果和 closed 收据。复用不产生新模型请求、计量、预算、Manifest 或 trace。
- Gateway 命中前检查原授权、当前持有者、来源和完整本地内容包；当前模型须可用且路由与原结果一致。命中后核对已知收据和累计活动时间，并再次校验来源。撤权、改源、改合同、不同持有者、停用/换模型、活动时间耗尽均不披露输出。
- 数据库要求有效事务 token、活动预算、成功且用量已知的 trace、最终 Manifest 和逐次已结算尝试；存在未知额度或未关闭调用时拒绝保存/复用。结果不可修改或删除，有结果历史时降级迁移拒绝执行。
- 保存瞬间失权/到期可见降级，已知收据仍关闭且实际用量记录保留；未知响应不生成可重放成功结果，也不自动释放或重新派发。
