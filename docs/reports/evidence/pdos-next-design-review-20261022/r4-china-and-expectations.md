# R4 · 中国研发管理/PLM/IPD 工具的 AI 化进展，与企业对 AI-native 研发系统的期待和顾虑

调研日期：2026-10-22。只读分析，未修改仓库。
对照对象：PDOS v1.1（`docs/design/2026-10-08-pdos-complete-target-architecture-v1.1.md`，下称 v1.1）及 `pdos-next/` 代码现状。

## 0. 先说结论（给 PDOS 的 8 条判断）

1. **国内同行在 2025–2026 年的 AI 化有一条共同路线**：先做嵌入式助手加“原生回写”，再开放 MCP/CLI 给外部 Agent，最后把“AI 节点”嵌进已有的审签或流程。ONES、飞书项目、TAPD、PingCode 都已上线前两步；飞书项目已把 AI 节点和 AI 字段做成可配置能力。PLM 厂商（华天、金蝶、鼎捷、思普）还停在“知识问答＋物料/BOM 辅助”，宣称多，能验证的细节少。
2. **国内没有一家把“研发定义＋NPI 准备＋证据＋分级 AI 写入”做成一个内核。** PDOS 的差异化成立：T0/T1/T2 分级、引用、运行回执、撤回守卫（v1.1 §06.5、§06.10）。竞品只做到“继承用户权限＋记录历史＋先审阅后应用”（ONES）。
3. **最大缺口在“在哪里办理”**。中国中小制造企业的协同基座是钉钉，官方口径是 7 亿用户、2600 万组织。v1.1 只在拓扑里写了“授权钉钉轻入口”（v1.1:1122）和“Connector Worker → 钉钉”（v1.1:1134），S0–S5 交付表没有排期（v1.1 §09 阶段表），`pdos-next/server`、`web/src`、`contracts` 里也检索不到 `dingtalk`/`钉钉`。阿维塔的教训很直接：独立的 AI 工具峰值只有几百次访问，嵌进已有审签流程后累计调用超过 6 万次（客户宣称）。
4. **Excel 是事实上的竞品。** 社区和咨询复盘都指向同一件事：BOM 在 Excel 里，图纸在微信里传，变更靠喊。PDOS 能解析 XLSX 原件（`pdos-next/server/pdos_next/evidence_processing/parsers.py`），v1.1 也提到存量型号可以从 Excel 导入（v1.1:298），但没有面向业务对象的结构化导入/导出（BOM、规格、测试结果、认证清单），也没有回写 Excel 模板。
5. **ERP 是“读”的缺口，不是“写”的缺口。** PDOS 已有固定外部移交和回执（v1.1 §04.14、`domain/external_handoff/`）。金蝶 AI PLM 卖的是“变更影响覆盖在途、在制、在库等 10+ 类 ERP 数据”。PDOS 的变更双线影响（v1.1 §04.13）缺少一个只读的 ERP 库存/在途/采购承诺连接器，否则“改一颗料要报废多少”只能人工填。
6. **认证与客户资料是 PDOS 的潜在强项，但缺少“证书生命周期”。** 品类种子已经区分法定、渠道、自愿要求（`docs/design/category-seeds/auto-tire-inflator.md` §4）。跨境品牌真正头疼的是证据链：电池 UN38.3、MSDS、规格书、制造商声明、CE/UKCA/FCC、GPSR 欧盟负责人这些文件按市场和渠道成包，实验室资质还会变化，报告也会失效。PDOS 应补上“证书/报告有效期与适用 SKU 映射＋渠道资料包导出”。
7. **数据安全顾虑排第一，而 P26 降低了默认防线。** 国内企业家调研中“商业数据泄露”顾虑占 57.81%；CIMdata 2026 调查中 IP 保护与数据保密占 68%。P26 把服务商数据协议改为可选、不阻断出站（v1.1:1068、§07.5）。这对自主品牌公开研究没有问题，但对 OEM/ODM 客户原件（客户图纸、客户规格书）应保留默认拦截或二次确认，并在 UI 上可见。
8. **“审批太多”和“价值不可量化”是 AI 研发系统的两个反噬点。** CIMdata：31% 的用户没有看到可量化收益。BCG：50% 的 CIO 无法量化 GenAI 影响。PDOS 的 T1 一次确认、双专业批准、具名签核都合理，但要防止中小企业觉得“比 Excel 还累”。建议把老板最在意的四个指标（版本错误报废返工、BOM 编制/校对工时、变更闭环周期、资料检索时间）做成效果复查（v1.1 §06.13）的默认看板。

## 1. 方法、证据等级与局限

- **证据等级**：A＝官方产品页、文档、发布说明；B＝权威第三方调研（CIMdata、BCG、Deloitte、McKinsey、信通院、IDC）；C＝媒体稿或客户案例（多为厂商口径）；D＝厂商营销/排行榜文章；E＝社区讨论。厂商效果数字一律标为“厂商宣称”。
- **局限**：
  - 本轮 WebSearch 配额（每轮 200 次，所有子 Agent 共享）在调研后段用尽，因此用友“研发云”的专门页面、思普 SIPM/PLM 8.0 正文、艾瑞 2025 制造业数字化报告正文、IDC PLM 2025 原文都没能读到，只用了检索摘要。
  - Reddit 无匿名访问通道（WebFetch 被拒，agent-reach 的 Reddit 后端需要登录态，未启用），所以 Reddit 观点只来自二手汇总。知乎原文返回 403，改用可访问的人人都是产品经理、V2EX 原帖和厂商渠道文章。
  - 国内厂商的 AI 资料大多是新闻稿。“已上线”与“规划/演示”的区分以官方页面措辞为准，无法实测。

## 3. 跨产品模式（AI-native 交互与业务能力）

| # | 模式 | 代表 | PDOS 现状与建议 |
|---|---|---|---|
| P1 | **嵌入式助手＋原生回写**：助手感知当前页面/筛选，生成结果直接保存为系统对象，继承用户权限，写入历史 | ONES Assistant、飞书项目 AI 助手、TAPD、PingCode 拼扣 | PDOS 小Pai 已覆盖，并且更严（分级、回执、撤回）。保持“写入前可审阅”的一键体验，避免每步都弹确认 |
| P2 | **把系统开放成外部 Agent 的工具**（MCP Server/CLI） | ONES（63 工具）、飞书项目 CLI＋MCP、TAPD MCP、禅道 MCP（V2EX 用户最看好的一点）、钉钉 AI 表格 MCP | **PDOS 只有 MCP 客户端准入**（v1.1 §06.2），没有对外 MCP。建议规划只读加 T1 预填的 PDOS MCP Server，让钉钉悟空/个人 Agent 能查询“这个型号的认证状态”“这批样品测试结果”；写入仍走受控命令和分级 |
| P3 | **AI 节点嵌入既有流程/审签**：AI 结果出现在审签界面，不增加步骤 | 飞书项目 AI 节点/AI 字段、阿维塔交付件预审与变更评审 Agent | PDOS 的 AutomationRule（v1.1 §06.4）在机制上等价。缺的是在 Gate/评审/测试结果界面“预审结果就地呈现”的界面合同。建议把“交付件预审”“变更影响初判”“相似历史问题”做成 G0/TR/变更页面的默认卡片 |
| P4 | **私域知识问答＋来源回溯＋私有模型** | 华天“华小天”（约 50 万文档、页码回溯）、金蝶研发知识助手（答案溯源）、2025-02 的 DeepSeek 接入潮 | PDOS 的原件定位与证据适用性更强。差距在**冷启动**：SME 的历史资料是散落的 Excel/PDF/微信文件，需要批量导入和整理向导 |

| P7 | **零代码自建智能体/技能** | PingCode 智能引擎、飞书 aily（阿维塔工程师约 2.5 小时搭出变更评审 Agent）、钉钉悟空/AI 表格、用友 Skills 构建器 | v1.1 §06.3.4 写了“先在对话中做对→保存为个人技能→共享团队”，但 §06.3.2 又规定技能包随代码发布，数据库只存启用状态。**两者有张力**：要么提供租户级技能（受评估门槛和 T0 资格约束），要么明确“个人技能”仅指提示模板 |
| P8 | **私有化/一体机/国产模型** | 用友 AI 一体机、TAPD 私有化混元、ONES 私有部署＋企业模型、华天私有模型、金蝶等保三级＋千问 | PDOS 当前用 MiniMax（国产）和阿里云 RDS/OSS/ECS，符合“数据不出境”。多服务商自助配置是后续方向（v1.1:1068）。建议把“支持接入私有化/本地模型（OpenAI 兼容）”写进对外卖点，并把等保要求列入路线 |
| P9 | **生态联合** | 金蝶×阿里千问、ONES×华为云 IPD、PingCode×火山豆包、钉钉×MCP 伙伴 | PDOS 的自然生态位是“钉钉＋GoodJob CRM＋金蝶/用友 ERP”的研发与 NPI 空档 |

## 7. 对 PDOS 的优先建议（按投入产出）

1. **钉钉入口落地**（身份、待办卡片、审批深链、拍照/文件回传、到期提醒）：补上“在哪里办理”这一最大缺口。
2. **结构化 Excel 导入/导出**（BOM、规格、测试、认证矩阵）：先消除“比 Excel 更累”的第一印象，同时作为不锁定的信任信号。
3. **认证证据的生命周期**（有效期、实验室、适用 SKU/市场、变更失效、渠道资料包）：直接服务跨境品牌和带电池品类。
4. **只读 ERP 事实连接器**（库存、在途、单价）：让变更影响和成本估算能算出“钱”。
5. **OEM 客户原件的默认出站防护与可见回执**：回应排名第一的顾虑，又不违背 P26 的“可选治理”。
6. **对外 MCP Server（只读起步）**：满足“AI native＝能被 Agent 调用”的新期待，并接入钉钉 Agent OS 生态。
7. **中小企业精简模式与价值看板**：降低上手成本，让老板看到四个指标的变化。
