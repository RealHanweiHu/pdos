# 统一品类 · 原工程开发检查点 · 2026-10-06

按用户最终纠正“市场空间、产品线、品类是同一个东西，都合成品类”，修改原 `server/`、`web/` 和3000本地预览。汽车充气泵与自行车充气泵分别建品类；技术平台可以跨品类复用。本记录替代0425历史检查点中的“空间包含多个产品线”设计，不改变原N/P/Q勾选、生产或人工出口。

## 可用结果

- 只创建一次品类，维护一套身份、地区、负责人、生命周期与成员权限。品类目录和品类内页面不再提供重复的空间／产品线选择器；型号直接挂品类，变体挂型号，族／系列为可选标签。
- 主API使用 `/api/product-work/categories` 和 `/categories/{category_id}/shared`，页面主链接使用 `?category=`。旧空间、产品线API和 `?space=`／`?line=` 深链接保留兼容，非法旧编号仍拒绝，不能扩大读取范围。
- 新提案由服务器绑定当前品类，固定当时的场景、可用竞品、地区法规与规格字典骨架。竞品、提案、定义和测试骨架引用相同参数版本；原未绑定产品线的共享记录可引用所属品类字典，原记录和历史不被改写。
- 客户需求和引用私有原件的提案继续仅负责人／当次具名评审人可读，不进入共享矩阵；具名确认去标识摘要后才能沉淀到品类。技术平台独立、多对多复用，品类视图只显示当前可读型号的关联。
- 原预览的两个空间现作为两个品类保留，原“自行车充气泵”提案可见。没有猜测重命名、拆分或合并原业务资料。
