# 独立产品经理角色 · 2026-10-04

按用户“帮我加入产品经理”授权，在原 `server/`、`web/` RBAC 增加第八种角色 `PRODUCT_MANAGER / product_manager`。`pdos-next/` 的独立授权模型未修改。

## 可用能力与权限边界

- OWNER、ADMIN 可创建产品经理账号，或在“设置 → 成员与角色”中将普通账号改为“产品经理”；角色分配继续留下原事件与审计。真实人员和存续账号未自动调整。
- 产品经理登录默认进入产品工作；可管理被授权市场空间、研究来源、研究/机会/实验、策略与产品定义，以及产品矩阵和路线图。需求创建/编辑、案例创建/编辑、本人工作、资料采集和 AI 候选办理沿领域权限与当前对象范围执行。
- 产品经理是内部协作成员，可被加入项目、指派为产品槽位评审人。具名产品评审通过不授予项目批准权；专业评审、当前来源、发布前置条件、具名发布及原审计保持。
- 项目创建/编辑、项目成员管理、Case 状态批准、Gate 最终决定、工程/质量槽位签署、工程写入、测试记录、成本/变更批准、系统和账号管理均未授予产品经理。案例界面的编辑与状态/立项按钮分别判断权限。
- 保留项目经理原有产品工作权限，兼容已在用的兼任账号；这次增补不替真实组织指定人员或调整旧人员的职责。当前会话从服务器重读角色，降权立即阻断后续操作，角色变更未另加会话撤销机制。

## 迁移与资格

新增单调迁移 `0417_product_manager_role`，前序为实际 head `0416_product_evidence_item_decisions`。扩展用户 CHECK、16 个相关数据库授权守卫，保留原范围/来源/幂等/历史守卫。存在产品经理账号（含停用账号）或保留的产品具名指派/签名时拒绝降级，禁止静默改映射或删除历史。

仅在本轮自建容器 `pdos-product-role-test-20261004`、本地端口 55708、独立 `pdos_test` 执行 repo 数据库测试。数据库 head/角色约束与 Agent 业务表零直接写权限见 [数据库事实](database-final.json)。存续库、真实账号、生产与真实模型未操作；已有目标库须应用 0417 并更新应用进程后使用。没有新增 AI 资格、T0 启用或 Agent T2 权限。
