# 管理员配置兼任模块 · 2026-10-04

用户要求：由管理员根据兼职情况打开对应角色模块，用户登录自动呈现本人页面与兼任模块。实现范围为截图所在的原 `server/` 与 `web/`，原 N/P/Q、65项状态和 `pdos-next/` 保持。

管理员在“成员与角色”中展开成员的“配置兼任模块”，勾选后明确保存，可增加或撤销产品、项目、工程、品质、PIE、供应和管理决策模块。主角色模块自动保留，系统管理不作为可分配模块。成员下次登录或重新加载页面读取最新配置；首页叠加主角色与兼任模块、导航取并集，产品兼任者的本人研究与定义直接可见，模块项目链接在选择项目后进入对应专业页。本人所有具名待办和既有审批权限保持，无用户视角选择器。

0419 在真实 0418 head 后单调追加 `users.work_modules`；成员创建/API更新支持配置，列表和当前身份投影读取持久值。管理员权限、租户边界及特权账户限制沿用原服务，外部账户不能配置内部模块；转为外部角色须清空模块，可与角色在同一事务中更新。变更与具名审计同事务，模块不授予专业资格、Owner/Admin 或正式签署权限；当前配置非空时禁止撤回迁移，防止静默丢失配置。
