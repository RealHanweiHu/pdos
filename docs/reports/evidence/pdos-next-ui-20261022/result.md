# UI 续建检查点 · 2026-10-23

本轮补齐小Pai的明确项目/个人范围切换、固定技能手选，以及品类经验候选表单；真实 MiniMax 已经由原 API → Temporal → LangGraph → 网关返回完成结果。整体 UI 仍为进行中，浏览器余验及下述领域依赖未关闭。

## 可用能力

- 小Pai可跟随当前页面、切换个人工作，或从服务器当前可见项目中明确选择项目；绑定真实品类、型号和项目，身份/页面变化后清除旧选择。
- 个人、品类与项目可手选已启用技能，提交固定版本与内容摘要。受理及执行前复核当前启用状态和摘要；手选替代默认预载。未启用、已变化、重复或超量选择在创建 Run 前拒绝；选择不授予写入资格。品类原未知请求仍保留原技能与幂等键。
- 品类知识目录可明确进入经验候选记录/续版表单，使用真实品类修订号和 null 型号；正式规则仍走型号、项目、实际配置与具名流程。
- 按用户本轮明确决定启用[本地开发 MiniMax 不限额策略](../../../design/2026-10-23-local-development-minimax-policy.md)：费用/次数/token 配额不阻止本地开发调用，真实费用和停止控制保留；默认和非开发环境继续执行原限额。使用官方 M3 输出技术上限 524288，未执行先前的 $0.25/一次预算预览。
- 结果校验失败时反馈具体字段路径与错误类型，例如 `questions.0.depends_on/list_type`；不放宽结构校验，不自动把错误模型值当可信事实。
