# 协议提示缓存政策与管理界面

2026-10-29。本增量落实上下文设计 §8 的协议缓存限制；真实模型、embedding 与外发均未调用，真实协议未更新。

协议原留存条款是自由文本，不用关键字推断缓存许可。新增 `ProviderDataAgreement.prompt_cache_allowed` 可空布尔事实，与数据类别一样沿既有租户权限读取。当前最高版协议有效时，仅明确 `True` 允许可控提示缓存，`False` 或旧 `NULL` 关闭；没有当前有效协议仍按 P26 返回允许，不新增出站前置。数据类别限制保持独立。`EgressDecision` 新增同名布尔字段，缺省为 `True`，供调用链和出站前复核使用。

原管理员 T2 登记表单增加默认不勾选的选择，列表、预览、续版与未知响应恢复保留同一选择。仅表达服务商接口支持的可控提示缓存，不宣称可强制关闭 OpenAI 兼容服务商的全部内部缓存。输入严格拒绝字符串和数字代替布尔值；未提供或显式 `null` 的请求在序列化时省略新字段，保留旧已批准请求的 `request_digest` 和回执恢复身份。
