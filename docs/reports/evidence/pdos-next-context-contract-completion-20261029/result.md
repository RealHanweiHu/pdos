本轮沿两份已授权设计补齐三项实现差异：历史来源改为冻结依赖后批量复核、Anthropic 临界窗口预先计数、登记的缓存许可控制显式缓存标记。撤权后整个 Run 被普通 RLS 隐藏的情形，新增本人原话投影与页面展示，沿现有工作状态权限读取，不新增数据库权限。

## 行为

- 历史正文不在每次模型前重新读取。39类 READ 的实际账本、来源及已携带历史构成依赖；更新保留旧答并标注，撤权隐藏，当前显式资料预检仍先执行。
- Anthropic 准入估计达到 F 的90%时，经登记网关和当前出站检查调用计数端点。计数单列技术账本；失败或超限停止生成，计数不冒充生成 usage。真实服务商请求仍关闭。
- 有效协议的明确布尔许可控制三处 Anthropic `cache_control`；旧协议未知值关闭显式缓存。无协议按 P26 不阻塞出站。OpenAI 兼容接口的服务商自动缓存不在本次通用控制范围内。
- 撤权后仅从既有 append-only 工作状态选择本人 `current_goal.text` 及真实 `recorded_at`，保留当前会话父范围检查。原结果、事件、候选及继续操作权限不恢复；页面保留独立新对话入口。旧记录缺生产工作状态时仍不可读，不伪造回填。
