# 产品到 ERP/PLM 主数据的交接引用候选

2026-09-30，按完整设计合同 D22、N0-01 与 N6-04 的原细则续建。定向核对发现现有 ERP BOM/ECN 交接、项目文件引用不能替代产品型号/变体与 Material/Product/CAD 主数据的关联；因此本轮补内部引用登记。此项是原合同余项，不新增主数据同步或外发范围。此前0408报告的“N6-04未发现必须新增缺口”只代表当时审阅，不能作为D22完成证据。

## 已实现的候选行为

实际产品矩阵标签的产品层级在型号、变体下接入“ERP/PLM交接引用”。人工登记系统、对象编号、外部修订与资料时点，关联已保存非空白正文的共享证据，并固定服务器读取的产品快照和最新生效发布定义编号、版本、修订、摘要及发布回执。Material 归 ERP、CAD 修订归 PLM，Product 可引用 ERP/PLM；没有当前已发布定义、产品退役、内容缺失或版本漂移均拒绝新登记/纠正。内部登记不表示外部接收、正式交接确认或主数据启用，也不复制外部属性。

纠正、撤回只追加记录。上一记录须是本产品活动链头；相同活动外部定位不能重复登记或撞另一条引用链。撤回冻结原外部定位、来源、产品和定义引用，即使定义发布已撤回或产品已退役也可在当前管理权限内办理。产品或定义变化将原引用标为需复查，旧历史不改写。空间归档仍沿既有只读边界。

读取采用当前岗位查看权限、空间/产品线只读授权；管理动作采用当前岗位管理权限及空间/产品线管理授权。服务从路径和登录上下文绑定范围，写入锁住空间；原请求先核对当前授权、原操作者及完整请求摘要，历史返回也重新核对来源正文。相同请求返回现有历史，不新增事件。事件、审计与引用在同一领域事务中写入；真实事务/锁/回滚仍待数据库联验。

页面按空间及产品隔离，旧响应不能回填新范围。401/403清除引用、来源、草稿和实际父工作区；在途读取或保存也不能重新展示拒权内容。网络/5xx/408/429保存结果不明时保留完整原请求与编号，只允许重试原请求；同时锁住产品树编辑、标签、刷新及返回市场空间。成功或明确拒绝后释放，409提示重新核对当前定义。恢复仅覆盖当前页面，不宣称跨刷新持久恢复。

新增源迁移 `0409_product_master_references` 接真实源head `0408_resource_guard_alias`。表与创建DDL相符，包含范围复合外键、单一后继、请求唯一性、对象/系统限制；迁移声明追加历史守卫、当前发布/产品版本检查、非未来时间、Agent零权限及有数据拒退。**本轮没有执行数据库迁移或这些数据库守卫**。
