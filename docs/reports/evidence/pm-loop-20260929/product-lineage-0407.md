# 产品经理闭环 · 竞品刷新与定义来源追溯（0407）

2026-09-30，归 N1-03/N1-06 及必要 N7-01 导出切片。沿现有产品经理候选补齐业务判断的来源状态；原 N 项、八能力 SHADOW、真实资格与人工出口保持。

## 已补齐的行为

竞品页刷新现在重新核对当前矩阵原来的观察编号，外部新增参数修订后仍保留原观察值，呈现服务器返回的“需复核来源或范围”。改变下一次比较的勾选不会替换正在核对的原矩阵。列表或比较读取失败时，旧值保留并明确标成待核对，不继续显示“录入条件一致”；重试成功恢复实际状态。明确 401/403 清除观察、矩阵、原文和编辑内容，范围切换后的迟到矩阵不能填回。直接、间接、新兴竞品及替代方案在只读卡片和比较矩阵均可见。

定义导出投影现在保存实际消费的固定 Strategy 引用，包括编号、版本、摘要和时点；全是假设、没有研究快照的定义也不丢这条业务来源。策略出现同系列新发布修订时，提示仍消费旧版，不自动换入新版。派生定义预览和四格式文件记录锁定父版及当前父发布状态：替代、撤回、没有发布或固定版本不匹配均提示，派生正文与本地覆盖保留。只输出必要引用和状态，不附策略全文。

策略和父定义分别按服务器绑定的租户、空间及产品线重新授权，不把业务对象引用塞进研究快照授权接口。新预览、同请求保存的既有回执分支、历史下载均经过业务来源权限核对。即使子定义仍可读，策略或父版撤权也拒绝返回旧文件；有权限时，父版状态变化不重写既有字节、摘要或快照。

本次来源投影标为 `definition-export.v2`，新增字段和段落兼容现有 `internal-definition.v1` 模板合同。兼容检查发现直接升级模板编号会违反数据库现行 CHECK，因此保留其受支持编号；无 schema/迁移变更。新增状态进入来源和预览摘要，状态改变后旧预览不能创建新回执；旧回执仍按其原编号和固定字节读取。旧投影与新投影摘要不相同，历史记录不能借旧摘要证明新版来源状态。

同时补齐产品评测四个路由的返回类型和已有矩阵评分旅程的调用边界类型，仅为修复受影响静态检查发现的问题，行为保持。
