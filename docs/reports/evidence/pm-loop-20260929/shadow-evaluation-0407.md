# 产品经理闭环 · 独立影子评测入口（0407）

2026-09-30，接续[派生权限与旧项目兼容](source-scope-0406.md)。补齐管理员独立评测的实际执行入口；八项产品能力仍为SHADOW，没有真实搜索、模型调用、资格发布或正式人工Exit。

## 问题与交付

原[逐能力评测器](capability-evaluation.md)仅有离线响应回放，普通产品运行又要求LIVE，无法在保持影子边界的情况下通过受控入口取得真实调用回执。现在新增独立评测用途及0407迁移，沿用当前应用网关、来源读取、预算、授权、租约、调用记录和结果检查点。

- 原发起人须为当前租户模型管理员；未建Project也可在市场空间下办理。七项产品分析及产品矩阵接入各自原提示词、结构和来源投影，普通员工运行的资格限制保持。
- 固定候选文件摘要、能力、样例、来源及执行合同。整份候选的租户/市场空间、实际来源、参考答案和消息结构在首次模型执行前核对；参考答案不进入模型请求。单例入口同样重验来源和合同。
- 模型选择仍由租户治理决定，请求的服务商/模型与实际选择不符时不出站；配置摘要只是待独立核验的声明，不能成为权限或资格事实。缺受控预算配置时拒绝创建运行，不回退旧调用方式。
- 调用前及结果保存时重验授权与来源；撤权、来源变化、停用、引用或结构不合法时不披露分析结果。重复请求复用原运行，不能改写原输入；已完成结果有数据库不可改写守卫。有持久结果检查点的中断可恢复原调用回执，不再次请求模型；未取得结果的未知调用不自动重发。
- 结果仅保留在私人管理评测记录，不产生Finding、研究任务或员工待办，不修改产品定义、矩阵处置或路线图，不授予业务资格。八项正式能力的入口、人工接受/应用及发布批准边界保留。

独立入口位于 `/api/product-work/spaces/{space_id}/evaluation`：`POST /prepare` 准备实际授权来源，`POST /runs` 执行固定单例，`GET /runs/{run_id}` 查看原回执，`POST /suite` 执行有原文件摘要的逐能力候选并生成报告。没有新增管理页面；本轮前端未改。

批量报告只比较规范化后的完整结构与事先固定的候选答案，输出来自网关规范化结果，不是原始服务商正文。报告保留私人运行引用和用量，同时明确独立调用证明、参考答案批准、配置绑定核验和模型资格均未验证/未授予；“候选答案匹配”不能宣称语义质量通过或业务已可启用。
