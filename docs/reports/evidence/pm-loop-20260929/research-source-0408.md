## 已补齐的行为

研究任务结论和工作结果提交现在通过现有来源解析，核对租户、共享快照、有效来源、原摘要和抓取时点，并要求已保存且非空白的正文。旧元数据快照、缺失或空白正文会在业务写入前拒绝；提示重新采集有效正文。原任务权限、负责人/接收人、范围、状态前提及幂等回执保持。没有来源的研究结论仍按原合同处理，不伪造研究证据；工作提交原有证据要求保持。

研究采集组件自身按市场空间与产品线隔离状态，不依赖调用者传入 React key。原实际工作台已有空间/URL 产品线的父级重建，本轮是组件直接使用时的补强，不把旧父入口误报为未隔离。原文、采集回执、来源/快照元数据、表单草稿在 401/403 后隐藏；明确重新核对成功才恢复可见资料。同范围重渲染不会自动恢复旧引用。引用阅读还核对原编号和摘要，引用数组顺序或对象字段顺序变化不会解除拒绝状态。

权限失败已接到实际工作台父入口：研究/工作卡、结论、成员、引用、编辑草稿一起清除；在途工作台读取或办理结果不会填回。回调身份在父组件普通重渲染后保持稳定，不由新回调触发隐式重新加载。显式重试恢复获授权的新资料，旧正文和草稿不恢复。

人工市场细分切换工作归属或空间会取消原文读取、清除旧正文/编辑内容；原文必须匹配引用的编号及摘要。列表/正文 401/403 清除市场资料并向实际父入口传播；迟到列表、旧正文、旧表单保存和计算返回不会改动新页面。同步重复保存/计算只发出一次请求。AI 市场候选的计算权限失败同样清除整批候选、来源与既有计算，不留下可继续确认的旧建议。

人工市场保存另补完整原请求恢复：网络/5xx/408/429 保留深拷贝正文与请求编号，锁住编辑、取消、重新计算和新保存，提供“按原请求重试保存”；明确服务器拒绝解除，401/403沿权限清除，成功先释放锁再刷新记录。实际工作台同步锁住标签切换、工作刷新、市场空间返回、AI 范围入口及成员写入，本地市场范围、历史和刷新也锁定。只读计算失败与 AI 候选本地核对不取得人工写入锁；原候选接受与独立应用语义保持。外部卸载释放旧页面锁，迟到回执不回填；不宣称新增了跨刷新持久恢复。

完整组件检查还发现研究搜索与订阅两个同级组件共用 React key，已分别命名，16 项研究采集子集复查无重复 key 告警。原 RFQ、派生、发布、竞品、矩阵的专项恢复按各自已有候选继续联合核对。
