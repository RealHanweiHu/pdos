## 修复与可用行为

通用资料准备与分析入口此前没有完整联动：历史或运行收到明确撤权时，上方已核对的原文、私人问题和选择仍可能保留；运行详情的拒绝不能清除这些资料；一个请求结果不明时，接续另一条历史运行还可能替换原请求。

现来源列表、资料核对、运行历史、生成、停止、运行详情及三类候选的明确 401/403 统一清除通用准备区的原文、问题、查询、产品线和来源选择，以及该分析区的历史、结果和待核对请求。失效前开始的读取/生成不再填回内容。市场空间、能力或外部产品线改变时，即使调用方未指定 React key，也使用独立页面状态。重新授权须读取来源和当前可访问的产品目录，旧问题和旧选择不自动恢复。

结果不明时保留完整原请求副本和编号，阻止另一个历史请求替换它。网络失败、5xx、408、429 保持待核对状态；明确版本拒绝允许修正输入。重复点击只发送一次。已有历史可按原编号恢复结果，确定性停止仍使迟到生成回执失效。普通历史/停止/候选连接失败保留最后一次可读取的原结果与上下文，区别于明确撤权，不因刷新失败重新发模型请求。

服务器仍提供当前范围、来源版本、资格与运行状态。未改变 API、数据库、AI 写入政策、候选接受/独立应用、RFQ 一次确认或正式发布边界。通用运行的候选拒绝联动包含研究计划、通用业务及 RFQ 候选组件；RFQ 上传/解析原件父入口尚需继续核对，本轮不将其回调测试冒充完整原件入口验收。原请求恢复限当前页面状态，未新增跨整页重载持久恢复。
