## 修复与可用行为

- 分析资料、路线图选项与本人运行历史原先在 401/403 后仍可能保留已读取原字段。现在任何来源核对、历史读取、停止或进度查询收到明确拒绝时，清除准备资料、选项、私有要求、固定原字段和待核对请求。子运行面板的拒绝同步通知上方资料面板；重新授权后从空状态读取。
- 市场空间或原对照改变时立即切换为独立空状态；离开范围后的迟到响应不再更新页面或发起后续历史请求。撤权前尚未返回的响应也不能重新填回资料。
- 新分析同步锁定完整原输入与请求编号。响应丢失、5xx 或无法确认的请求保留原资料摘要、路线图选择、要求和编号；“重试原矩阵请求”提交完全相同的原输入。待核对期间锁住新分析与要求，来源准备发生变化也不会改变重试输入。
- 刷新历史找到原编号的终态回执即可解除待核对状态，无需再次生成。正在执行的原运行保留待核对与停止/读取入口；明确的服务器输入拒绝解除本次提交状态并显示重新核对原因。
- 已收到终态回执而历史刷新失败时保留回执，明确提示已保存及刷新路径；不把读取失败误报为需要重新生成。原租约接续与累计预算、来源检查、资格及人工办理边界保持。

待核对的完整输入仅保留于当前页面状态，未存入浏览器持久存储；重新进入页面仍应读取本人历史，按保存的原运行接续。本轮没有增加后台自动重试或新的模型执行权。
