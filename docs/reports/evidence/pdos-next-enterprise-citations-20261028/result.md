2026-10-28。完整目标仍为日常助手/企业 RAG v0.4 与上下文 v0.2；本检查点只交付 Artifact/UploadedOriginal、品类知识上的受控问答基础。当前能力与剩余工作统一见[唯一清单](../../../../tasks/ai-native-integrated-todo.md#current-queue)。真实模型、embedding、真实业务外发、生产和 git push 均未执行；测试使用显式独立 pdos_test、本机 Temporal、合成提供端口和合成原件。没有写入 golden-case 或授予实际资格。

## 可用能力

- `assistant.search` 返回权威权限过滤后的元数据，并从实际已完成读取账本签发本 Run 的固定引用；租户、本人、范围、版本、哈希和扫描依据均由服务器核对。`assistant.extract` 只接受已签发的引用，跨 Run/伪造引用被拒绝。
- 不可信原文在独立 `assistant_extract` LangGraph 子图内通过 `assistant.passage.read` 有界续读，物理工具表只有这一个读取工具；不提供技能加载、写入、联网或 MCP。主循环只收到核对后的证据行。证据引文必须是子图实际读取页的逐字子串，原生定位、读取量和覆盖由服务器推导；结构化品类知识直接返回固定字段，不额外调用提取模型。
- 引用继续复用不可变 `AgentToolCall` 与真实模型/读取绑定，未新增另一份权限表或模型可修改的来源事实。恢复复核原账本与当前版本，不重新调用模型。最终依据状态、记录数、来源、版本、引文和 locator 由服务器生成，忽略模型伪造的来源与计数。
- 每次模型发送前，服务器从本次实际读取及真正进入上下文的历史/续读页推导资料类别，再执行现有 P26 协议限制；缺少协议仍按 P26 办理。未明确纳入处理目标的检索资料不能直接进入写入/准备候选、研究搜索或 MCP 出站；完整 I14/I22 携带与行动续接仍待后续。
- Run 详情和引用原文入口重新核对本人权限与扫描状态；撤权/撤回隐藏依赖内容，正文中途失效则清除依赖自由文本并返回 partial。版本或知识 Current 指针更新保留原回答及旧引文，标注已更新；运行内冻结的历史只因撤权停止。跨过最近十轮、经实际 `conversation.history` 追加读取的来源同样受复核。
- 回答展示服务器来源、固定版本、定位、未知项和查找提示；原文只在用户明确点击后按同源有界页读取。资料更新保留旧引用并提示重查，撤权清正文；卸载后的迟到响应不恢复内容。BFF 严格限制 GET、游标和页大小，拒绝 URL 身份/范围参数，使用 no-store。
