# 两份小Pai设计续建：会话工作状态基础

2026-10-28。完整目标保持为企业 RAG v0.4 与上下文 v0.2；本检查点不是全部设计完成，也不是完整 X2 验收。活动状态只见[唯一清单](../../../../tasks/ai-native-integrated-todo.md#current-queue)，完整范围与依赖见[验收对照](task_plan.md)。用户“暂不调用真实模型”继续生效。

## 可用能力

- 新增 `agent_work_states`，按会话追加版本；运行结束和工作状态在同一事务提交。完成、partial、普通失败与本人取消接入；已失权的失败仍沿用原技术收尾边界，不借记忆取得写入权。
- 根目标、当前目标来自实际用户 Run；现行页面材料边界后的文字不作为用户目标或约束证明；模型只能在 `result_json.context_proposals.constraints` 提议约束。服务器核对同一会话中用户原话的连续逐字片段，拒绝改写、捏造、其他会话与用户已移除的条目，记录接受/拒绝原因。
- 保留范围对象的实际版本及明确选择资料的固定版本引用、真实领域回执、实际候选/技能事件引用，以及明确作为非事实的未完成项和问题；取消或无输出失败继续保留先前未完成项。模型自称完成的动作不进入工作状态。
- 本人接口支持读取、移除约束、标记已携带资料“不相关”和移除排除条件；严格版本比较、原请求幂等、冲突恢复及删除记录防止约束复活。接口不接受权限、租户或任意来源扩张参数。
- 本次携带在运行开始冻结，并进入既有上下文快照合同；运行中修改只影响后续运行。来源有更新时标注；撤权、撤回或扫描失效时隐藏相应来源与派生说明，已冻结内容撤权会停止继续模型发送。
- 仅复用 session_id 不能携带未绑定的旧资料或较宽的出站分类；必需状态未完整载入或超出 1.5k 初始预算时，图在模型调用前返回 partial / `context_incomplete`。
- 续聊输入区新增可展开的“本次携带”，展示目标、约束、焦点数量、待处理和隐藏说明；支持移除、原请求恢复、资料“不相关”及刷新。打开和刷新只读，弹层可滚动。
- 生产投影删减的字段名通过服务器信封显示给模型，不带值；字段清单也校验快照，篡改即拒绝。
- 修复两项旧目录检查：技能检查遍历当前唯一注册项而不固定 17；合同检查仍精确核对冻结的 87 操作 / 86 主事件 / 63 验收 ID，额外 4 个事件必须标明 auxiliary 且逐条匹配已登记辅助命令。未改变写入档位或辅助命令的实际实现。
