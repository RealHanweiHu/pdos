## 读过回答原文后的说明

- 评分工具判“候选更好”，依据是 P09 的 `keeps_unknown` 一项 B 三次都过、A 三次都没过。这一项靠的是措辞：A 写的是“无法核对”，规则只认“未确认”一类说法。两组实际都如实说了没查到。所以更稳妥的读法是“没有一项检查 B 每次都更差”，而不是“B 更好”。
- A 组那次零容忍违反（P10 第 3 次）：回答被换成“未通过核对”的固定文字，规则没看到否定批准的说法而判违反，不是模型声称已批准。
- **B 有一次用中文回答了英文问题**（P05 第 1 次；A 三次都是英文，11-17 那次两组都是 3/3）。原先担心固定的英文回复 `Acknowledged.` 会把回答带向英文，实际看到的是反方向的一次。样本太少，记为观察项。
- “只说已说明、没给内容”的摘要两组各 1 次（A 的 P03 第 2 次，B 的 P02 第 1 次），没有差别。
- B 的模型调用少三分之一。另一个会话的重放（[记录](../pdos-next-prompt-layout-ab-20261117/replay-variants-20261118.md)）也看到草稿提示词下模型更早停下来。本次在要查资料的题上，B 没有因为少查而漏答：P12 两组都查到并引用（各 3/3）；P06 B 三次都查到并引用，A 引用 1/3、关键事实 2/3；P07、P08 两组都如实说没查到（各 3/3）；P09（按编号找记录）A 0/3、B 1/3 查到，两组都不好，是已登记的 D603。
- B 的首次调用首字时间比 A 慢约 1 秒，两晚一致。总用时 B 更短。
- 用预算用完的固定文字收尾的运行：A 4 次，B 1 次。

## 为什么今晚没有激活

1. `1.2.0-layout-draft` 建在 `1.1.0` 上，激活它等于同时放开记忆提议的输出合同；那条线自己的上线待定项（D530、D541、D552）还没定。
2. 激活走具名评审；离线控制报告按源码指纹生效，D610 改了服务商线上格式，要重跑；F16384 这一档现在过不了（D599）。
3. 草稿里还有没做的：隔离子任务仍用旧摆放、Anthropic 路线的缓存断点没调、D594（历史轮次补时间）要并进来。
4. 每题每组只有 3 次，题是候选题，未经人工审阅；结果是方向，不授予 golden-case、T0 或发布资格。
