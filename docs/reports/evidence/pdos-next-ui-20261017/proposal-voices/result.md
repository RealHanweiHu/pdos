## 可用结果

- 新增 `/v1/categories/{category_id}/proposals/{proposal_id}/voices`。复用原文档读取器的当前/具名评审冻结身份，只取本案明确引用的固定知识版本；不把品类全部声音混入，也不按文本猜测规格关联。
- 标签/摘要与原文分别显示，只有通过来源守卫的实际 `quote` 才呈现为引文。登记样本数沿用固定知识由服务器保存的去重结果，逐条显示，不相加为总样本或占比。人工/AI/导入来源、版本变化、具体条目关联及完整来源身份可回查。
- 资料撤回、版本不符、底层来源不可读等只显示安全引用与原因，不返回旧标签、原文或推测值。无法判断种类的不可读知识引用使用中性提示。切换文档/品类或同一冻结身份刷新立即清旧，保留错误、重试与迟到响应隔离。
- 新增两条精确的 Next 静态 BFF GET route：矩阵与提案声音，复用会话 Cookie、限定品类/提案、保持 `no-store`，拒绝写方法与额外范围参数。没有改并行施工使用的 catch-all route。
