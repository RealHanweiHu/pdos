# 小Pai 新文件上传 · 实施候选，验证未闭合

接续已登记来源候选；按 HTML 编辑器附件入口及 v1.1 §05.4/§05.5/§07.6 实施。已完成真实上传与原请求恢复，尚未完成本轮全部浏览器核对，不宣称整体闭环或阶段验收通过。

## 已实现

- 输入区选择/拖入单文件，服务器读取真实 Category/Product 目标版本和本人写权限。沿用既有原件事务，支持原合同 TXT/MD/PDF/XLSX、非空且不超过 8 MiB；本入口默认仅本人可见，提案只提供上下文，不自动挂载为提案资料。
- 新只读回执入口按本人、范围、原 nonce 和规范摘要读取实际 RequestKey/Receipt/UploadAttempt。明确区分 committed、reserved、abandoned、not_observed；未观察到回执不推断零写入或失败，预约不推断字节已保存。
- 保存后展示实际原件、扫描、安全和解析状态。只有解析形成且通过现有可用性守卫的 Artifact 才进入已登记来源选择；原件版本与 Artifact 版本分列。上传本身不启动 Run、不确认需求、不自动携带资料。
- 本地仅保留原请求元数据、nonce、文件哈希与摘要，未存文件字节。刷新只 GET；需要重试时先核对原请求，再要求原文件相同字节，沿用同 body/key。权限失效隐藏私有资料且保留原指针；切范围/异步晚到均阻止向错误范围发 POST。存储不可用时可保持本页内存恢复，不新增强制 localStorage 业务规则。
- 专属 BFF 在认证/同源检查后校验上传格式和流大小；8 MiB 的 base64 及元数据允许通过，超限在 BFF 拒绝，不受旧 catchall 较小上限影响。既有其他可见性合同保持。
