## 可用结果

- 品类六标签中的“品类矩阵”读取 `/v1/categories/{category_id}/category-matrix`；支持一至十个精确十进制展示分界，默认 150/300 只是展示参数。
- 服务端按照可读型号的固定目标细分版本落格。目标价必须与同一读权下、已批准非变体 G0 的冻结文件及保存口径一致，且来源通过现有守卫；不能以型号身份补造价格来源。
- 币种、原日期、价格类型、税、运费、地区、渠道七个维度分别成组。空格显示“暂无可读记录”，缺关联/缺源/撤回单列原因，保留原口径与来源详情。
- 前端保留我方橙色强调、120px 细分列和横向矩阵；未知价格有明确文字。支持读取错误、重试、非法分界提示和过期响应隔离，不产生业务写命令。
