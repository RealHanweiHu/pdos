## 现在可用

- 在项目 Builds 明确选中轮次后，先重新读取项目范围的 Build，再读取既有型号级 `build-execution`。按 Build/项目/版本、计划与实际双配置、Lot、分配和样件逐层核对，只显示所选轮次；其他合法项目记录不混入。缺父链、错版本、重复和矛盾引用要求重读，不从计划或其他轮次补齐。
- 显示实际双配置、各批次观测原时点与系统收到时点、服务器产出及已登记单件标识数；保留来源需重核与合成性质。服务器标识计数与本次可读样件行数分别保留，不以可读行数覆盖服务器事实，也不合成库存或可用余量。
- 样件按登记显示模穴、工序、保管人、位置、去向、固定身份及创建原时点；null/空字符串明确未登记。保管、位置、去向和可用性都是分配登记时字段，不推实时到达、预约、消耗或当前可用。旧 DTO 的 `reservation/consumption=null` 不进入投影，更不作为不存在的证明。
- 型号级 `unavailable_count/has_more` 明确标注为型号范围，不能当成本 Build 缺失数或完整总数。未完整读取时不声称零样件或全部产出；无试模轮次/模具合格结论。
- 范围、本人、API、Build、页面读版本及刷新变化清旧数据；提交后的布局清理和迟到回包守卫防止旧失败误伤新页面。503 可独立重试，权限/来源/协议失配隐藏父轮次。仅读取，无业务写入、轮询或 localStorage。

仅新增两个读取文件和三个独立组件文件，在自有 `project-build-summary.tsx` 最小挂载并补一项父子隔离检查；新增一个真实读取联验测试。未改共享 API、BFF、领域生产代码、模型、命令或迁移。
