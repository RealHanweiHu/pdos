## 实施结果

- 独立 `ProjectCommitments` 面板替换占位，复用现有 `readProjectWork` 与既有 BFF GET。仅增加三个组件/CSS/检查文件及项目工作区最小接入；未改共享读取库、服务、命令、模型、迁移或自动化文件。
- 只展示服务器 `status=current` 的人工任务承诺，按独立记录保留承诺人、接收人、约定成果键、固定任务版本及原时间。默认显示3条，明确已读计数并可展开其余；不宣称已覆盖测试开测、供应及外部承诺。
- 固定 `task_revision` 与当前任务版本分列；当前任务名称和成果说明明确只是当前上下文，不能冒充承诺时的固定正文。缺少固定版本/登记时点直接显示资料不完整，不回填当前任务版本或创建时间。
- 日期未知保留；已知时间、原时区、日历及 `recorded_at`/`created_at` 分别原样显示，保留微秒和时区偏移。姓名仅取当前可读成员；缺失不补造名字，完整标识收进详情。只读成员仍可读取，不把写资格变成读取门槛。
- “当前版本”不等于未结或已履行；当前任务验收不自动移除承诺。显示“履行待核对”和“履行结果尚未汇入”，不从缺少履行读集推断尚无履行事实。
- 按本人/品类/型号/项目/readVersion重新隔离；API切换和手动刷新同步隐藏旧数据，迟到成功/错误不能恢复旧私有资料。加载、失败和空态分别显示。无轮询、业务写入或 localStorage 事实缓存。
