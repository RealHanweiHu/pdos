## 现在可用

- 项目“现在”的关键承诺同时读取既有 `project-work` 和独立 `project-work/fulfillment`，不从任务状态推断履行。分别显示“已具名核对履行”“已退回·履行保持开放”“尚未具名核对”；尚未核对不表示事实未完成。
- 两次 GET 是独立快照，发布前核对项目/型号版本、当前承诺集合及每条固定身份/版本、接收者/承诺人/范围/原时间与当前任务头。缺投影、错版本、集合变化和矛盾核对状态要求重读，不补成 open 或零条。两份原 `as_of` 分别可查，不声称同一事务。
- 履行只关联精确承诺 id+revision，不按 task 或 series 继承旧结论。旧版已履行、新版待核对分别保留；同任务不同接收者不合并，任务验收也不替代履行。
- 当前核对及历史显示具名人员、核对版本、服务器原登记时点、逐项意见和回执。历史 DTO 未提供当次固定的任务/提交/承诺引用 tuple，不拿当前材料补历史，不把登记时间叫实际完成时间，也不以 fulfilled 宣称来源当前有效或当前可批准。
- 延续本人/品类/型号/项目/API/readVersion/刷新隔离；任一读取失效清旧结果，迟到回读不能重现旧私有资料。只读，不使用 can_review 发起决定，无 commands/localStorage 写入或新轮询。仍仅覆盖人工任务承诺。

只改自有 `project-commitments.tsx`、CSS 和专属测试；新增一个实际读取联验测试。共享读取库、父项目工作区、BFF、模型、命令和迁移未改。
