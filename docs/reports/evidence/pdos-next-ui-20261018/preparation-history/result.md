# 制造资料历史与基线固定正文

“工程与制造准备”现可按原游标翻阅制造草稿历史，并从基线明确展开其固定 WI/CP 正文。指导书系列续到 v2 后，引用 v1 的基线仍读取原 v1；不从当前文档补齐历史。默认显示实际基线名称与固定版本，完整身份和保存时指纹收入可展开详情。

依据指定 HTML、v1.1 §04.3–§04.4、§05.3/§05.12 及确认稿 P13/P21/P22。当前版只表示资料系列头，保存时缺项不重算为当前成熟度；不产生正式发布、资格或阶段通过。

## 实现

- 制造列表新增原 `history_cursor` 透传及 `nextCursor` 读取。每次服务端返回全部可读 Current 和单页历史，面板整页替换，不混合旧 Current、不累计 `unavailable_count`；空历史页仍可保留下一页位置。共同 BFF 仅制造查询分支接受有界原游标，固定版本和 inputs 不接受历史游标。
- 子文档严格取自所选基线的完整固定 binding，按 kind/id/revision 发 GET，核对项目、固定工艺和工序；成功读取前不显示旧正文。切换基线/文档、翻页、刷新、身份/范围/API 变化、收起和卸载均隔离迟到响应；权限或协议失败隐藏旧资料。
- 展示原步骤、参数、控制项、未知、来源、时点、版本、保存缺项及回执。正文接口不返回 `body_sha256`，因此绑定指纹仅是保存时事实，界面和读器明确不声称本次已复验哈希。
- 本轮只改两个读器文件、三个面板文件、共同 BFF 的制造查询一处，新增专属 BFF 测试和一个 PG 病例。没有改生产领域、公共模型、命令或迁移。

## 候选边界与未覆盖

最初检查副本守卫拒绝整个当前 BFF 覆盖，因为其中同时包含现场反馈施工的新材料校验，见 [initial-copy-guard.json](initial-copy-guard.json)；尚未启动产品检查。随后只在副本叠加本轮制造查询修改，保留工作树全部改动。进行中的现场反馈选择/订单等 [前端差异](concurrent-source-boundary.json)和[共同 BFF 差异](concurrent-bff-delta.diff)不在本轮构建通过声明内，不以这个候选证明整个当前工作树通过。

实际历史页长为 **50**，本病例所有返回游标均为空，**真实跨页与有效下一页游标未验证**。原游标编码/透传、页面替换、不可读计数、过滤空页和迟到响应由定向前端/BFF 检查覆盖；没有为此造 50 次续版，也没有构造客户端有效游标冒充服务端回执。实际固定正文未包含小数字符串，数字保真仍仅有定向前端覆盖。保存时哈希与原体的关系由本例后端核对，正文 GET 没有新增可供客户端复验的哈希字段。

此前 55210 浏览器操作被明确拒绝，本轮未探测、重试或换入口绕过；新正文展开、历史翻页、320px、亮暗和完整标识视觉复核仍缺，未新增实际 BFF 整链或模型调用。既有上传超大 JSON 中断和其他已知失败未关闭。
