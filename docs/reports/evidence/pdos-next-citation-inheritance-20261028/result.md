## 可用能力

- 从服务器 `continued_from_id` 链中的实际搜索账本重建来源，验证原模型/读取绑定，并复核当前本人权限、受众、撤回与扫描。同一 session ID、模型给出的 UUID、推导出的未签发 CID 都不能代替实际读取证明。
- 子 Run 冻结状态首次只带 3 条重新签发的引用；`assistant.citations.read` 按原 CID/实际交给祖先的别名定位，或按稳定游标分页，每页最多 8 条。正文不进入预览；不可读来源不进入标题、计数或更多提示。
- 新 CID 固定到原来源身份、版本、hash、定位，并记录原 Run/原 CID。实际提取、隔离段落、服务器回答来源与页面读取使用同一账本。真实新增知识版本后仍读原知识版本，回答标为历史；原位置正文已改变时拒绝用新正文替换旧引用。
- 仅继承元数据不能产生已引用的公司答案。实际提取后，本轮即使不重复搜索，也能得到服务器引用、时间与来源链接。AI 写动作仍保留显式携带、当前资格与 T1/T2 守卫。
- 工作状态保留紧凑的原始引用指针。界面显示固定版本与历史依据，“不相关”追加工作状态版本并供后续轮次排除同来源；丢失响应重用请求编号，移除排除不改写已冻结的运行状态。
- 新工具接入既有恢复与历史读取端口。实际 HTTP→Temporal→注册 LangGraph 两轮链、来源页面、重复提交及无重复提供器调用通过，正文标记不进入 Temporal 历史。
