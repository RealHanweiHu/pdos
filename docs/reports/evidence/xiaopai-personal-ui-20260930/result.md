# 小Pai个人 Agent UI与自动上下文修正

2026-09-30，用户明确个人Agent定位及“从当前页面自动取上下文，不先选项目”。本次在主工作目录保留既有Linear风格进行修正，不提交或推送，不修改业务库/schema/迁移/模型资格。

## 已完成

- 全局入口改为独立dot，面板标明个人Agent；完整页与侧面板使用同一Provider。关闭Next开发指示器，截图中的N菜单不再占据产品入口。
- 移除项目选择器，自动从当前页面的路由、工作范围及工作对象解析上下文。项目读取以服务器返回的可访问项目清单为边界；不默认选第一个项目，不把产品/设置页面附到上一个项目。
- 展开完整页保留来源URL，刷新可恢复范围；关闭回到来源页面。A/B项目组件保持挂载，未发送草稿在跨页/收起/展开期间保留，运行仍绑定原项目。
- 读取当前用户已渲染的页面文字作为可展开的上下文预览，限2400字符，不读取输入、隐藏状态、其他页面或文件。此预览不上传模型或共享；非项目后端对话尚未接入时保留草稿并显示明确状态。
- 个人Agent默认只载入本人private会话；明确打开共享链接仍显示项目成员可见。持续委托使用独立共享会话ID，不把私人会话或资料提升为项目共享。
- 问答界面移除外围卡片与办理模式前置选择，消息/输入为主，历史/附件/持续委托按需展开；旧领域入口的标准模式不变。
