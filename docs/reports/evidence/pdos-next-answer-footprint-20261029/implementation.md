## Confirmed gap

`checked_sources()` reauthorizes every actual `ledger.carried()` source. However, the previous knowledge `capture()` used only `answer.citation_ids` plus the Run's initial `read_sources` to derive provenance and privacy. A successful search/extraction can disclose private/customer source B and produce unconstrained prose influenced by B while citing only shared A. Since `private_context` describes admission, it cannot substitute for this later actual read. `assistant_reviews.prepare()` and the original native candidate/category guards received that reduced proof and classification.

The existing native tests cover cited/bound private sources, browser visibility flips, native T1/T2 adoption/replay, current source revocation, private matrix provenance, and Human deidentification. They do not cover this uncited actual-read path. This increment focuses on that gap; it creates no question set, golden case, T0 qualification or professional history.

## Changes

- `assistant_sources.capture()` retains the requirement for at least one real checked citation, but includes the complete actual carried footprint in fixed proof, classification, actual source products and fingerprint. Uncited reads become dependencies, never fabricated citations/quotes. Conflicting fixed versions fail closed instead of winning by dictionary order.
- `assistant_storage.SOURCES_KNOWN` and the matching unnumbered schema extend only the native membership check. Root reads must be sealed completed ordinary/main calls tied to the actual model position, exact immutable Run/ReadBinding fields and recorded tool disclosure. Inherited sources use the same linked conversation, explicit disclosed history turns, unresolved fixed work state, and reissued original citation identity. There is no generic JSON/UUID walk and no cross-conversation scan. The old reviewed-knowledge closure and bound-artifact branch remain intact.
- Upgrade/downgrade pins use the normalized actual `schema_s0_0841.NATIVE_FUNCTIONS` definition. No new runtime EXEC grant is introduced. Downgrade refuses existing contribution proofs that citation-only provenance cannot retain, under table locks and explicit per-fact tenant selection; original rules and old proofs otherwise retain their path.
