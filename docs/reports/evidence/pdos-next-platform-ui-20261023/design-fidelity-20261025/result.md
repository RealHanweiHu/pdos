- 我的工作：责任/期限列表优先，继续提案和继续项目在后；收件箱改为通知/聊天/关注动态及列表—详情并排；项目列表去除多行卡片结构，知识入口与目录改为平面紧凑行。
- 窄屏：提案编辑/聊天切换不再互相遮挡，切换保留输入；资料候选编辑在手机单独占据可用区域，收起后继续原对话。
