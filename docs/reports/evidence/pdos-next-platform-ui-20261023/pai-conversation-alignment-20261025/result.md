# 小Pai对话界面对齐 · 2026-10-25

用户反馈正式小Pai界面与确认版不一致。本轮对照已确认的 `ui-lab/platform`，收拢正式个人页、品类/项目页内面板的对话布局。前端修订，无后端、迁移、业务保存或新模型调用。

## 已实现

- 将“发起工作”和“继续工作”分离的表单合并为一个固定底部输入区；打开历史结果后在原位置续聊。Enter发送、Shift Enter换行，中文输入法组字不触发发送。
- 顶部只保留会话标题、历史、新建与会话信息；范围跟随当前品类/项目或显式选择。实际技能记录、办理分级收进会话信息，引用/过程/撤回/反馈收进详情；错误、待答复和待确认动作仍直接可见。
- 用户消息使用中性色块，AI正文减少边框，保持已实现的大编辑区与旁聊结构。新会话保留附件、自动技能与携带资料的紧凑入口。
- 恢复与授权守卫不变：续聊先读取资格、沿用原run和服务器范围、原请求精确重试、已存在后续只打开、401/403清理本地材料。修复开发StrictMode在效果清理/重放后自动读取续聊资格卡住的问题。
- 同时修正品类工具栏在侧聊宽度下的标题换行和状态选择器比例；上下文面板限制宽度并提供下拉提示。
