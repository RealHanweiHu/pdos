# 小Pai 运行控件简化 · 2026-10-25

用户要求“停止后续执行”和“转后台继续”参考常见聊天产品。正式个人/品类/提案聊天已移除正文里的两枚大按钮：进行中发送位改为圆形底上的实心方形停止图标，停止后恢复发送箭头；后台继续收进顶部“…”菜单，菜单支持Escape关闭并返回焦点。

停止按钮为type=button，有明确的可访问名称/提示、忙碌禁用态；仍调用原当前运行的cancel路径，保留既有请求锁与失败恢复，不触发发送或另建运行。后台行为复用原收起/返回同一运行逻辑，不产生请求。原运行记录及等待输入时的取消入口不变。

验证：50项相关组件/会话/续接检查通过，覆盖个人和品类的单次取消、重复点击锁定、终态恢复箭头、后台不发请求及原有权限/未知请求守卫；类型与受影响lint通过，布局静态检查0项。最后只增加菜单aria-label与演示页border token；git diff --check通过。截图running-controls.png。

浏览器核对正式页已结束会话没有运行控件。进行中视觉与交互使用 /ui-lab/pai-controls 的明确标注本地演示，直接复用正式PaiScope与RunContinuation组件，未调用模型或API。核对菜单后台继续→返回、方形停止→发送箭头、Escape、可访问名称；没有取消用户已有运行。本轮无数据库/后端更改，不宣称真实运行取消整链、全站构建或移动明暗矩阵已重新验证。预览仅允许localhost/127.0.0.1。
