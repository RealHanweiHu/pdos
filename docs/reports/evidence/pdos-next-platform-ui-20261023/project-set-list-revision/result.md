# 项目集列表 / 看板修订 · 2026-10-23

用户要求项目集与“项目”一样采用列表或看板，避免文件夹式侧栏。当前候选只保留一个与“项目”同级的“项目集”入口，主页面支持列表 / 看板，页面内新建与编辑，详情内批量移入项目。全部项目列表和集内项目行可更换归属；原集数量、未归类过滤同步更新。

预览：[项目集](http://localhost:57859/ui-lab/platform?view=sets)。当前按一个项目归属一个集或未归类演示；这是可讨论的预览关系，尚未冻结正式领域模型。看板由成员项目健康状态汇总，不新增审批或权限根。
