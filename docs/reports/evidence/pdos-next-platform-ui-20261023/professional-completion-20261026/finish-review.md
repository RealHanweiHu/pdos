# Impeccable 完成检查

沿用 `web/src/app/ui-lab/platform/DESIGN.md` 与用户已确认的新布局，不另建视觉方向。

本轮按 Impeccable 要求执行一次独立只读完成检查。发现并修复：

- 项目范围拆分后，物料/成本的旧本机草稿和待定原请求可能丢失入口。现按真实项目 Build 读集迁移，保留原命令、键、确认凭证；范围不完整时停止迁移，旧记录保留。制造准备也保留旧键恢复。
- 物料/成本读集的 `freshness` 与 `captured_at` 未进入摘要。现历史和需重算分别展示，保留真实采集时间。
- 长列表展开详情缺少焦点与滚动反馈。现展开定位标题，收起回到原按钮，带 `aria-expanded` 和详情关联。
- 现场反馈接续必须使用公开逻辑 ID，不能依赖可选别名。已修正并测试。

主会话随后完成 1280px、390px、320px 与明暗检查：全页没有横向溢出，宽表仅在自身容器滚动；14 个新增索引统一紧凑工具栏、平面表格、详情与按需维护。实际记录→原业务组件的接续、待定请求保护及权限失败行为均有回归覆盖。

收尾中另修复同轮次路由接续导致持续 loading、失效变更来源锁住其他选择、项目动态聚合超时；这些由浏览器与定向回归复核，没有再启动独立设计检查。
