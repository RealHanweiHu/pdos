# 项目任务页细节优化 · 2026-10-23

范围：`/ui-lab/platform?view=tasks` 合成设计预览；没有业务、数据库或模型操作。

- 工具栏分为视图、阶段/来源/状态/负责人筛选、搜索与新建三组；宽屏同排，较窄窗口筛选独立换行。
- 搜索移动至右侧，以轻边框和统一高度融入工具栏；支持清除按钮、Escape 清空、清除后恢复输入焦点，忽略首尾空白。
- 所有负责人固定 112px，筛选统一 30px 高度、12px 字体，右侧预留 26px 箭头区域；选中条件有中性背景反馈。手机控件 36px、筛选双列。
- 列表图标、编号和名称垂直居中；固定列比例，长标题省略并保留原名提示；键盘焦点与行悬停清晰。保留桌面 40px / 手机 44px 行高与 NPI / 额外任务。
- 合并重复 CSS，保留看板、详情、NPI 引用及共享任务行为。

验证：14 个浏览器检查通过，包含搜索/清除/焦点、负责人及来源组合、空态/Escape、看板、NPI 详情、长名称额外任务保存、离线禁用；1440、1024、390、320px 布局及明暗截图人工核对。ESLint 与 TypeScript 均退出 0；浏览器警告/错误为空。详情见 [检查记录](browser-checks.json)。
