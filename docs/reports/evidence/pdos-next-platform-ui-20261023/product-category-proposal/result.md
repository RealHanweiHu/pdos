# 产品经理、品类与立项提案优化 · 2026-10-23

范围：完整产品合成预览 `/ui-lab/platform`；不改正式业务 UI、数据库、权限或模型调用。

## 可用能力

- 产品经理“我的工作”收拢为紧凑责任清单，增加本人“继续提案”，保留承诺、已完成和项目入口。PD-042 关联页打开对应 S2-L 草稿，不再落到 P1 或非 P1 项目占位页。
- 品类入口增加可搜索列表；详情以共享知识为默认视图，保留规格字典、型号、品类矩阵。当前品类的提案通过辅助查找面板进入；客户 RFQ 原件从共享品类移入私有提案。
- 立项提案增加状态、品类和搜索筛选。详情以问题、关键定义、方案取舍和待决问题为主，右侧只放提案属性与引用依据；四个业务视图及证据/版本记录共用同一提案。
- 本地私有草稿可新建、跨页保留编辑、增删规格与待决问题、保存新修订并回看旧版。G0 提交预览须选择具名评审人，提交固定当前版本；已批准记录只读并跳转对应项目。未提交草稿不会新增项目。
- 小Pai自动携带具体品类/提案上下文，展开与收回恢复相应对象。
- S2-L 作为 S2 定义 v1 的新变体草稿，区别于已存在的 S2 项目；避免把同一个 S2 同时表示为未立项草稿和已执行项目。
