# 资源需求融入计划与本人工作 · 2026-10-23

用户明确批准移除“资源协调”独立入口，将功能融入项目的工作与计划和我的工作。当前实现只涉及完整产品 UI 原型。

## 已完成

- 项目页直接进入项目三视图，移除全部项目 / 资源协调二级导航。独立 Portfolio 页面、搜索入口和覆盖表跳转一并删除，旧 `?view=portfolio` 映射到工作与计划。
- 项目计划展示设备与人员、替代时段、供应需求。点击资源行与本人工作使用相同事项详情，显示两项目影响，方案比较按需展开。
- 项目负责人、品质人员的协调事项进入“要我协调”；管理者跨项目取舍继续保留具名决定。新增 QA-020 与 RC-08 仅为明确标注的合成核对案例。
- 方案 A 保持当前顺序；方案 B 在品质本人核对替代资源后可选。本人一次确认记录所选方案及影响，完成状态与结果可回看；同步项目计划、四时间及项目列表。原承诺、实际预约、适用样件接收、测试执行保持分开。
- S2 只显示自身资源需求和共享冲突，不套用 P1 的工作包或物料。手机详情保留完整标题、按需比较及正常尺寸的单选控件。
