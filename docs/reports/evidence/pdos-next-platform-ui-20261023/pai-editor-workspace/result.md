# 小Pai独立编辑区与会话标题精简

2026-10-23，用户要求将聊天内的长表单移入独立大编辑区，保留旁边继续对话；历史会话只显示标题。

## 可用能力

- 品类、竞品、用户声音、规格参数与立项提案复用独立编辑区域，左侧主编辑、右侧340–420px小Pai；聊天内无表单。正在编辑的草稿收为标题入口。
- 当前会话/消息绑定编辑目标，跟随同类后续候选；字段修改、关闭重开、手机编辑/聊天切换保留内存草稿。取消收起编辑区；原确认保存、来源、版本与权限守卫保留。
- 编辑区独立滚动、底部保存按钮保持可见；桌面提案名称/入口同行，窄屏纵排。消除全局表单样式叠加的多余间距。
- 历史会话34px单行标题，省略长标题并保留完整标题提示；品类与运行状态副标题移除。搜索、归档和置顶仍存在。
