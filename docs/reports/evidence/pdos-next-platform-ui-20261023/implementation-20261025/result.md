## 可用能力

- 项目任务共用真实计划/执行记录：列表与四列看板、来源/状态/执行人/未指定/搜索组合筛选、清除筛选；已经关联执行任务的计划记录去重。不提供绕过任务承接/成果验收的拖拽改状态。
- 竞品/用户声音：独立编辑区，人工新增和修订；竞品价格保留原币种、日期、税运、渠道和地区，规格保留参数固定版本、上下限、性质和工况；声音保留平台与来源。原有固定来源和细分关系沿用，可补具名来源说明；样本量仍由服务器计算。
- 知识资料撤回、查看已撤回、按同一谱系恢复、版本历史接现有领域命令/读取。规格字典新建、发布修订、历史接 `category.parameter.publish`，旧提案不自动换版。
- 保存后保留编辑区和旁聊；版本冲突由服务器拒绝，未知保存仅明确重试原幂等请求；成功回执后读回失败也保留原请求，防止重复新建。
- 页内小Pai携带资料类型、固定对象/版本、未保存字段、来源说明和撤回草稿；全部明确标为用户输入，随本人发送才提交，服务器范围和权限绑定保持。原请求重试固定原材料。401/403 清除私有编辑、续聊恢复记录并阻止迟到响应恢复正文。
