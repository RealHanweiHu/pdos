# 小Pai 可折叠处理过程 · 2026-10-25

用户要求按截图显示可折叠的过程：简短进展段落穿插灰色工具动作。正式个人、品类旁聊和历史消息已统一接入真实运行事件，放在回复正文上方；原有上下文详情及独立运行记录保留。

- 默认处理中展开、终态收起；用户手动展开/收起后，状态刷新不覆盖选择。时间来自原运行快照。
- 阶段文案是公开事件元数据对应的摘要，不是模型私密推理原文。已加载技能、实际工具开始/返回和等待/失败保持真实；未知事件和工具参数不进入过程区。
- 工具开始/返回合并为紧凑动作行，多轮处理不重复堆叠相同过渡文字；未记录返回如实标注，不把返回等同于成功、批准或提交。长历史保留既有“查看更早过程”分页，权限失效清理对应会话。
- 无新卡片外框，保持灰色12px动作行与简短段落、原有双主题变量；单层折叠支持键盘。
