# 品类资料与小Pai维护预览 · 2026-10-23

本轮依用户要求，让竞品、用户声音和规格字典通过小Pai新增与维护，自动携带当前品类上下文，并保持现有紧凑列表和轻量面板。仅修改 `pdos-next/web/src/app/ui-lab/platform/` 的设计预览及对应设计/进度文档。

## 可用交互

- 列表工具栏「小Pai新增」，记录详情「与小Pai一起维护」；自动带入资料类型、品类、原记录版本和未保存的输入。
- 候选可直接编辑或继续对话补充，主要字段展开，其余字段与原版对照折叠；确认后回到所属资料列表。小Pai结果保留 AI 草稿来源，缺失专业条件保持未知，不制造实测或来源。
- 修订、撤回与恢复追加版本；参数键保持稳定，旧提案继续引用原版本。过期候选拒绝覆盖人工新版本，重新带入当前版本后可继续。
- 候选绑定发起时的品类，切页不会重定向保存目标；不同记录指代不会误套到当前绑定记录。取消不保存，离线、权限不足、缺失必填来源均不能确认。
