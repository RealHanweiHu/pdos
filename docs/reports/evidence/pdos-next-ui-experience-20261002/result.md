# 2026-10-02 · 新工程前端入口与使用体验

用户授权同步优化前端，参考既有竞品入口研究，采用 Linear 风格，减少不必要入口，保留重要未实现能力的入口。本次在当前主线 `pdos-next/web/` 落地，范围为导航、结果展示与输入展开方式；当前业务领域包沿各自施工合同继续接入。

## 可用体验

| 使用场景 | 本次结果 |
|---|---|
| 进入工作区 | 我的工作、产品、项目、组合与资源、知识构成主导航；设置和小 Pai 留在低频区域。侧栏可收起为带可访问名称的图标。 |
| 查看产品 | 总览显示实际定义版本、可见项目、试制数量、证据状态和下一步。计数来自现有授权 API；读取失败显示未知并提供重试，分页未完保留说明。 |
| 办理专业工作 | 产品研究与定义、项目计划、试制和测试分层进入；齐套、成本、交样、开测、结果等子步骤有直接地址。原受控领域动作、确认和权限由既有业务组件保留。 |
| 阅读和输入 | 已有定义和项目时先读结果，编辑按需展开；从项目记录准备计划会展开输入并选中对应项目。来源录入、新委托及已结束工作收起。访问过的面板保留挂载，导航不清空草稿。 |
| 找到工作 | ⌘/Ctrl K 搜索实际产品和已知入口，可直接进入成本、结果等子步骤。地址保留产品范围及既有定位参数；未知或跨域子步骤不会激活错误面板。 |
| 未来能力 | 竞品对比、机会与实验、矩阵与路线图、反馈、问题与变更、评审与交付、组合与资源保留重要入口，并明确尚未/正在接入和当前可用的替代路径。 |
| 视觉与手机 | 中性色、细分隔、紧凑列表和图标标签；沿用 Geist、Phosphor、8px、橙色亮 `#c2410c`/暗 `#fb923c`。手机导航使用原生 dialog，支持 Escape 与焦点恢复。 |

参考既有 [竞品研究](../../../research/raw/npd-competitor-scan.md)及目标架构入口合同，并核对 Linear 官方 [My issues](https://linear.app/docs/my-issues) 和 [Teams](https://linear.app/docs/teams)。沿实际产品/专业边界组织工作区，未引入新 UI 库。
