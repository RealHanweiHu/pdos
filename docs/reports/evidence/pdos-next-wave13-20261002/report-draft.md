# 第十三波报告草稿：明确接收范围到实际开测

**待主线收口，本文不构成验收通过声明。** 本波按[执行方案 §12](../../../design/2026-10-02-pdos-next-execution-plan.md#12-已接收范围到实际开测的后续合同)实现 Run 计划、具名承诺和实际开测。最终候选、PostgreSQL 联验、页面操作及业务 Start 的结果由主线补入下表；早期通过记录不代替最终候选验证。

## 与已完成内容衔接

承接[第十二波结果](../pdos-next-wave12-20261002/result.md)的制造就绪/暂缓、实际 sample/item 方法适用、交样、部分接收与退缺项。沿用同一 SampleUnit、BuildLot、ActualConfiguration、Build 和正式请求不可变版本链。准备资料、专业方法、实物就绪、品质接收、承诺和实际开始保持各自依据与时钟，制造开工或外部产出不自动成为测试开测。

首版每个正式请求只建立一个 Run，计划覆盖该请求**全部明确已接收的 sample/item 范围**。未接收、暂缓、实际方法未知和资料缺项继续阻断；如需多个 Run 子范围，须先扩展领域合同，不能用某个子集代替整请求承诺。

## 已实现的办理路径

| 动作 | 固定内容与结果 | 占用边界 |
|---|---|---|
| `test.run.plan` | 采用服务器可信整版资源事实，固定完整已接收范围、实际配置和方法、执行者、设备/校准依据、环境条件与完整窗口；保存 planned Run | 不预约、不消耗、不生成实际开始 |
| `verification.schedule.promise` | 具名品质承诺绑定同一 Run 版本与计划摘要；正式请求推进 scheduled，Run 仍为 planned | 零占用；承诺开始与实际开始分开 |
| `test.run.start` | 固定原计划，核对当前专业资格、完整窗口、共享容量、样件使用与实际事件；正式请求 executing、Run running | 请求/Run 新版本、正式资源占用、逐样件预约或破坏性消耗、回执/审计/事件同事务保存 |

三项均为共同 T1：只读核对取得完整读集，服务器给出实质预览，具名人一次确认并原封提交返回的命令。来源、资格、配置、资源或样件事实漂移须重核；请求结果未知时保留原命令、原 key 与载荷恢复，不另造一次消费。已取得成功回执后的刷新失败单独提示，避免重复提交。

承诺与开测使用独立、显式的带时区事件时间及精确原文行。服务器核对整行 JSON 的 request、Run、用途、操作、发生时间和执行者，拒绝重复键、额外字段与无时区时间；实际开始不得在未来，须晚于相关接收并处于固定窗口。接收时间由服务器保存，预览以空值占位，不用系统当前时间补造发生事实。

界面按明确选择的 Build 读取详情，历史只读；能力取当前对象的服务器职责/资格结果，产品写权限不授品质或测试职责。running 回读本 Run **已提交保存的资源占用与样件使用**，展示资源版本、完整窗口与用量，并明确这是历史效果，不能证明当前空闲或当前专业资格。合成事实与合成开测始终有明显提示。

## 复用、并行与存储边界

复用已有 verification/resource_readiness 核、正式请求版本链、实际样件与配置、专业事实、共同确认/回执/引用保护和现有 UI 栈。指定的 89 份旧资产与验证包已做[哈希复用核对](reuse-review.json)；该范围不代表整个旧工作区无差异。

三路独占并行：A 实现可信测试资源与样件使用端口，F 实现 Run/请求适配与推进，C 实现办理界面及定向存储负例；主线统一 API/BFF、共同角色与命令、迁移和集中验证。沿同一共享资源占用表互查 Build 与 TestRun，不新建互不相知的占用账本；锁顺序覆盖产品、请求、Run、共享资产与样件门栓。

数据库守卫核对完整 Run 样件集合、逐样件配置/覆盖/实际事件、完整资源用量及窗口，并对孤立预约或样件使用执行延迟原子检查。资源占用必须绑定同一个物理 asset/resource 身份及当前有效的共享镜像版本；不可变历史、作用域/RLS 和 Agent 业务表直接写入限制继续保留。新增存储测试为 3 项、8 种故障，覆盖同 Build 错样件、少资源、错用量、错覆盖、错事件、错物理资产、孤立样件使用和孤立资源预约，核对事实、指针、epoch、确认消费状态及回执/审计/事件一起回滚；**实际执行结果待主线填入**。

共享 asset/sample epoch 采用保守校验：仅有完整、精确的本 Run 已提交证明时才扣除本次自身增加的一次 epoch，其他变化仍触发重核。即使另一项占用没有时间重叠，其 epoch 变化也可能使旧预览或旧 Run 的当前重核不再成立。本波不承诺自动释放、自动续资格或将此情况视为仍可执行；已保存历史效果保留，不改写成零占用。
