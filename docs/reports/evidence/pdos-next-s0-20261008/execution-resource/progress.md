# B4 实物、资源与开测：施工记录

当前主库 `s0_0717`；只使用本轮已核对的独立标记库 `127.0.0.1:53502/pdos_test`。按用户提速调整 P10，B4–B6 仅做受影响验证；最终性能门槛不变，统一在 B8 测量。以下表格保留 P10 前的历史证据，当前批次仅在文末以一段状态记录，活动状态以[唯一清单](../../../../../tasks/ai-native-integrated-todo.md#current-queue)为准。

当前实现：

- 专业 Current 存储签署事实摘要，读取按当前指针和水位判断；旧签署人及原事实导入人的普通授权期限不改写已发生历史。
- `s0_0411` 在写入时维护 29 类实物/资源/验证对象的固定受众依赖身份集合；读取逐项核对实际范围、当前对象受众和直接来源，不重走祖先闭包。派生集合由数据库生成，不接受请求体作为权限事实。
- B4 的 GET 与读取输入端口显式使用只读、可重复读事务。相同事务内的实物投影、完整直接集合和标量复用；写命令只在实际型号依赖锁下复用，锁升级刷新实际 ORM 值，flush/Core DML 使标量失效，SAVEPOINT 回滚清除授权与来源证明。
- 已开工 Build 读取保存的准备度、批准、开工和自身占用结果，只比较 Current、直接来源、引用资产和具名决定水位；另一次合法资源分配不触发重新分配本 Build。新的开工/开测放行仍由 owner 在依赖锁下完整核对一次。
- 私有开测资源端口在真实 UOW、完整资产及样件门栓锁下共享一份绑定材料；身份、事务/嵌套事务、写入水位或运行注册表改变时重新加载。真实资格/资源和执行窗口仍独立判断。
- `s0_0412` 为实际应用角色补齐已有开测/结果原子性断言函数的执行权限，保留领域表/RLS/触发器约束。
- `s0_0413` 允许普通开工批准、制造/测试资源事实不限定有效期，解除样件数量和占用数量的固定 CHECK 上限。真实资质、校准、维护、容量、执行窗口和人工显式临时期限仍逐项判断；材料不再传递一个最早 TTL。
- 专业 assessment 携带完整实际事实的生效时间和适用操作，末端按同一职责/资格规则重新判断当前时间；多项有效资格中的一项到期不自动否定仍有效的另一项。
- 实物、开测和结果列表读取完整可见集合；原报告候选位置不再限制固定 10000 行，保留原件字节、单行字节、解析深度和精确绑定/唯一性检查。资源端口的权限、资格、取消和来源失效分别映射到统一错误类别。
