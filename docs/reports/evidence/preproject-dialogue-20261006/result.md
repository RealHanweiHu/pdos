# 品类与立项提案的小Pai对话入口

日期：2026-10-06。范围：用户当前使用的原 `server/`、`web/` 与3000本地预览。未修改 `pdos-next/`，未push、启用生产或授予真实模型资格。

## 可用能力

- 品类资料直接作为页面主体；移除立项提案列表、大区块和新建表单，只留一个打开当前品类小Pai的入口。已有提案放到小Pai的辅助弹窗中，原深链、文档编辑和具名评审保持。
- 新建品类打开个人小Pai。按用户明确选择，只问会改变方向的问题，边问边研究；每轮最多三个关键问题，推荐答案不自动选中。用途决定品类边界，其他缺项保留显式假设。澄清答案继续原对话，普通会话协议不受影响。
- 结构化候选在弹窗中完整显示边界、资料、参数或提案方案/规格/来源/风险。受控公开搜索与原文读取接原研究进度、工具观察、回执及来源守卫；品类就绪候选须有真实保存的研究回执，搜索失败允许显示缺口，不能假装资料已查全。
- 保存按T1一次人工采用：服务端固定本人会话、成功运行、候选摘要、当前来源、权限和时效，在一个事务中调用原品类/字典/共享知识/提案领域服务，并生成不可改写回执；同一候选重试只返回原对象。品类另要求具名确认去标识的共享摘要，原私人对话及客户文件不进入共享资料。ODM提案按私有权限保存，参数ID、版本、单位、测试条件继承品类，AI不能自行置为“已确认”。原T2立项评审和规格冻结保留。
- 隐藏会话不会弹窗；恢复历史需要手动打开候选。保存201成功后才清除本次等待状态并跳转，避免未完成提示拦截合法保存。
