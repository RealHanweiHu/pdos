# 个人工作与跨品类项目投影 · 2026-10-16

本批把“我的工作 → 项目列表/经营总览 → 单项目驾驶舱 → 个人运行接续”接到真实后端读取。依据冻结 v1.1 §05、§08 的跨品类个人权限投影和 §08.11 一致性/读集规则，继续 M3；没有改变 G0 批准、领域写入或阶段验收规则。

## 可用能力

- 新增本人会话的项目分页、项目直达和本人运行摘要三个 GET 入口。各请求在普通权限的只读 RR 快照中批量读取；不借助特权函数或扩大品类权限。
- 项目读取实际 G0 固定定义、当前计划、工作包/任务数、具名负责人和未决事项。仅投影摘要，不读取定义规格、原件正文、计划输入或 Run 结果正文。来源撤回显示需重核；资料不可读与未创建计划分别表示，未知日期保留未知。
- 前端连续取完全部项目/待答复运行页，不再逐品类、逐型号、逐项目扇出，也不把第一页当完整集合。单项目驾驶舱直接读取所选项目。
- 本人的个人与品类运行统一显示，最近明确取 12 次，待答复完整翻页。品类切换后查看个人 Run 会清除品类范围，接续原 Run，不自动创建任务。
- 三个页面都有刷新及明确错误；加载或失败时不显示假空、假零或沿用旧项目。单项目“经营总览”正确返回总览。修复项目列表窄屏挤压，以及刷新时新全局链接被旧工作台链接映射的问题。
