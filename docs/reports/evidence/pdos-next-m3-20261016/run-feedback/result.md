# M3 / S1 小Pai私有运行反馈（2026-10-16）

基于 `f6db414`，按 v1.1 §06.14 补齐个人、品类与提案内本人反馈入口。可记录六类具体问题、补充说明、选择实际加载方法，并回查原模型/方法版本。完整 M3/S1 未判完成。

## 可用能力

- 私人反馈追加到实际 Run 的技术事件，当前本人和范围每次重验；普通只读成员可以记录本人的反馈，AI 身份不能使用此写入端口。反馈不修改领域事实、批准、资格、golden-case 或运行状态。
- 服务器绑定原 Run 的模型、路由、工具定义、提示前缀与实际方法加载事件。禁止客户端伪造版本或引用其他 Run 的方法；未知版本保持为空。原请求重放不加载当前模型或技能目录。
- 原 Run 加锁、原子追加；同请求并发只落一条，相同编号不同内容拒绝。历史完整分页，原请求可独立精确查询。反馈文本不进入默认模型上下文或过程投影，读取不加载 Run 目标/结果大字段。
- 页面首次展开才读取。响应不确定时保存同一请求并冻结表单，刷新只读原记录；显式重试也先查询原编号。入口复用个人/品类/提案现有运行，不启动新任务或模型调用。使用说明见[手册](../../../../runbooks/xiaopai-run-feedback.md)。
