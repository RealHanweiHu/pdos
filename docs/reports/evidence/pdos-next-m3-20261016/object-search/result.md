# M3 · 跨品类对象查找与连续跳转

已完成四类对象查找闭环：在全局外壳或独立提案页，用名称或完整 ID 查找当前可读的项目、型号、立项提案和品类，直接打开原对象。M3/S1 尚未完成。

依据 v1.1 §05 的页面/键盘契约、§07.7 精确对象检索与 AT-49；基于 `43fc903`，无迁移、写权限、Agent 工具或依赖变更。

- 个人读取接口在同一 RR/RLS 快照内联合检索对象元数据，不逐品类扇出，不读取原件、提案正文或计划内容。完整 ID 和完整名称优先；`%`、`_` 按字面查找。
- 跨类型分页绑定原查询和类型，锚点每次按当前权限核对；权限撤销后结果消失、旧分页需重新搜索。BFF 只放行明确的 GET 条件。
- 全局搜索用 ⌘K / Ctrl K；品类原入口查找保留为 ⌘⇧K / Ctrl Shift K。已打开的弹窗继续保有焦点。点击结果保留真实品类/对象身份，独立提案页也能回到全局对象。
- 读取失败保留输入并可重试；改变输入或关闭弹窗会使旧响应失效。空结果只说明当前条件下没有找到可读对象，不推断业务上不存在。
