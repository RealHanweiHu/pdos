## 已实现

- 运行详情返回只读过程投影，个人/品类/提案复用同一面板。显示实际已保存调用及真实业务提交数，明确区分处理返回、部分结果、待答/失能、失败、取消和业务批准。
- 步骤、绑定依据、回执各自完整分页；首屏 25 条、最多 100 条。元数据投影采用 RR 快照，当前源/对象/RLS 每次重验；专用过程读取不加载 Run 结果/版本大字段、工具结果/参数或原件正文，也不读模型增量原文。
- 完成、失败、模型不可用和取消在原 Run 事务中追加状态事件，回滚不留半条记录。终态历时固定；运行中含等待的历时按服务器观察时刻更新，旧历史没有结束时刻则保持未知。
- 分页失败可重试，权限错误隐藏缓存，原运行读取失败卸载过程视图。原始模型输出和内部推理不进入面板，公开说明由实际登记的行动类型投影。
- 顺带纠正上一候选管理员核对后的后台取消传参：使用现有双参数端口，避免把本地类型错误误报成执行服务暂不可用；真实核对与预算收尾保持不变。
