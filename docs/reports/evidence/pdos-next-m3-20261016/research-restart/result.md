- 只有服务器绑定的 `research.fanout` 编排可以接续原 started 调用；原模型、搜索和网页调用继续保留未知结果守卫。编排用独立连接的会话锁排他执行，不跨网络等待持有业务事务。
- 原调用派生固定作业 ID，首次保留任务与实际规格字典版本计划；未完成作业遇参数计划变化拒绝继续。台账已保存但父调用未结算时，从原作业文件恢复，不重新研究。
- 子图使用检查点前核对真实模型/读取回执、技能说明与原文件，恢复已完成的来源状态；检查点文字本身不授予引用资格。来源缺失、回执或正文不一致时不发新网络请求。
- 修复已复现的不同作业共用子检查点问题：同一 Run 内问题相同的两个作业现在独立执行，同一作业仍复用原线程。
