# 默认公开研究宿主、子图检查点与快照登记 · 2026-10-16

已把现有公开研究能力接入默认 API/Worker：服务器 Searx 配置 → 只读隔离研究子图 → 实际搜索/读取账本 → 逐字核对台账 → T1 人工登记快照。研究正文和台账保存在共享私有作业卷，主图/子图各有独立 PostgreSQL 检查点。基线 `d164713`；无新增迁移或前端，源码摘要见 [source-manifest.json](source-manifest.json)。

## 交付与实际结果

宿主元数据文件增加可选 `research` 块，默认 Bootstrap 用当前 engine 绑定领域权限、作业文件和研究服务，不需注入完整适配器。搜索使用现有 Searx HTTP 实现，网页/PDF 沿用固定 IP、地址/重定向检查、分页、限流及隔离解析。出站前重验当前 Run/提案绑定与服务商协议，回执只记录 provider、资料类别、协议版本和检查时间，不记录查询或网页正文。缺少检查点时拒绝子图，不回退内存；研究卷或配置不可用时保留其他业务入口。显式测试端口注入继续优先。

[默认进程用例](checks/pg-process-checked.log)通过实际鉴权 ASGI/lifespan、本地 Temporal 和完全默认 Worker `main()` 完成：主循环加载公开研究技能 → 派发一个子任务 → 搜索 → 读取页面 → 以实际快照和位置提交逐字片段 → 服务器生成台账/覆盖/失败 → 主循环准备快照登记 → 本人实际预览确认。独立回读有 **1 份实际品类快照、1 份绑定原 Run 的登记回执**；原命令重放为同一回执。模型仅有 7 次合成调用，按合成费率/用量在实际账本结算 **840 微美元**，占用归零，见 [business-result.json](business-result.json)。这不是外部模型的真实费用。

测试明确在页面加入一段不属于引用的合成正文：该正文进入只读子任务和快照，未进入主模型消息或事件接口。最终台账只有一条逐字核对行和一份实际读取证明、失败为空。重新构造默认 Bootstrap 后，从原不可变账本恢复同一 `job_id` 和内容，模型请求设为禁止；此项验证的是完成账本的恢复回调，不允许终态 Run 发起新调用。

同一真实 PostgreSQL 中核对到 **2 条检查点 thread**：主图一条、研究子图一条；子图已完成的工具只含 `research.search`、`research.read`。本批未在研究子图中途杀进程，不能将这两条 thread 当作生产恢复或研究中途进程恢复演练。合成阶段日志见 [worker-phases.log](checks/worker-phases.log)。

## 配置和剩余边界

参见 [公开研究运行手册](../../../../runbooks/pdos-next-public-research-runtime.md)和[模型宿主手册](../../../../runbooks/pdos-next-tenant-model-runtime.md)。API/Worker 都需要同一私有持久目录及已核对检查点；研究服务端点/目录变更后重启，模型/凭据/费率保持逐次读取。

默认出站回调现阶段沿用完整 Run 的资料类别，本次 API Run 为 `internal`，分别登记了搜索与站点的**合成**协议。**公开查询按实际字段投影、完整私有标识检查，以及用户结果中固定来源/覆盖的投影仍需继续收敛**；不能据此宣称未签约站点对所有公开查询均可正常使用，或三入口完整研究出口已通过。这些是后续独立建设项，不以缺少真实密钥作为暂停全部工作的理由。

本批只替换网络传输：官方 KMS SDK 响应、模型客户端、Searx HTTP transport、网页 transport 和 DNS；研究服务、图、领域权限/回执、费用、作业卷和 PostgreSQL 均走实际实现。实际搜索质量、站点连通性、服务商材料与模型资格、生产卷/Temporal 恢复、正式性能和完整 M3/S1 出口未完成。

真实模型、KMS、搜索、DNS、网页外部调用均 **0**；golden-case 写入 **0**，无 push 或生产操作。未修改前端，不重复构建、浏览器或攻防检查。
