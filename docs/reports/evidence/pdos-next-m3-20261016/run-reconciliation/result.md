## 可用行为

- 品类与个人小Pai共享核对入口。当前管理员只能提前办理本人且当前可读的运行，普通用户保留查看及自动核对。普通待答问题不被关闭，结果未知不能用答复来重发调用。
- 原 Run 加锁，以实际 RequestKey/作者/操作/Run 核对真实业务回执；已提交 Claim 与回执保留，有凭证的调用补记完成，无凭证的记失败。有业务动作时显示部分结果，始终保留原目标未完成提示；新请求可继续，迟到旧执行与未提交候选被旧版本隔离。
- 调用、Run、预留释放、未知费用估算及追加核对事件在同一事务内；故障完整回滚。真实核对事件是唯一技术凭证，模型业务 JSON 同名字段不能冒充。重复原请求返回同一记录。
- 超时自动核对仅执行技术 Activity，零 LLM/领域重发/外部重发。数据库暂不可用时持久重试，间隔上限 1 分钟；原执行仍最多三次重试。未知费用保留有界估算，未冒充真实账单。
- 读取仅投影技术元数据并分别分页，不带原始参数、模型正文或他人私有内容；失权与不可读回执拒绝继续。原撤回接口仍需业务写权限。
