## 可用能力

- 读取实际本人/品类/提案 Run、会话及原模型调用，消费同一 Run 内已结算 `evidence.extract` 的 `rfq_requirement/v1` 行；复核原件版本、扫描、引用、解析库存与覆盖。模型不能另传一份客户值，外来或未完成调用不授予读取资格。
- 明确参数引用保留实际固定版本；没有引用时，以当前字典的唯一精确键/名称提出映射。歧义或不认识的参数保留待映射，不猜同义词、不升级历史参数。映射不写入业务表。
- 客户值、单位、工况、单边上下限、否定与例外保真。缺单位/工况、不同版本/口径、部分重叠或来源变化继续显示未知；字典默认值不填入客户要求。
- 比较沿用现有标准品引擎，只核对指定且当前可读的共享型号及实际已发布定义。输出逐行来源、映射、代码生成的行数与映射统计、未知/差异、原抽取覆盖/失败及后续建议；非规格要求不会被当作全部满足。
- 私有内容仅来自已绑定并核对的本次抽取；重验当前提案受众和 Run 的资料类别/客户标识。型号来源在出站前仍按原共享对象守卫逐项检查。旧对象比较、私有全文/任意来源读取未因此放开。
- 同键原调用重放重新核对固定来源与字典结果，返回原回执；来源或自动映射结果改变时拒绝旧结果。仍是 `ordinary/v1` 读取，不提供 computed Claim 写入资格。

`calc.spec_compare` 工具版本升为 3，RFQ 技能为 `0.4.0-draft`，静态前缀保持静态；原对象比较的结果/摘要结构保持。技能或模型版本变化后的资格仍须按 v1.1 重审，本轮不授予资格。
