# 小Pai按技能投影资料与快照恢复

基于 `9dcffdf`，补齐 v1.1 §06.3、§06.7–8：十二个技能包声明可执行的本地上下文 schema，展开内容纳入技能 digest；先按实际已加载方法组装，再校验和投影。公开研究/品类澄清不预装提案正文，渐进加载工作方法后可追加当前绑定提案。系统提示和工具定义保持固定。

Run 与事件同事务保存快照引用、字段范围、schema/内容摘要、方法绑定、确切原件读集及范围元数据，不另存正文；同一投影重放原引用。模型发送前核对上下文与实际快照，原来源/权限/协议守卫继续执行。开发、测试有字段被删即报错；生产删减时记录原因，必要字段或类型错误在全部环境拒绝发送。处理过程展示实际省略数量与原因，刷新后可回查。[办理与配置](../../../../runbooks/xiaopai-context-contracts.md)

## 修复与边界

- 新图首轮合成协议只允许原件类别，内部资料被正确拦截；修正合成协议类别后 10 项通过，未放宽实际出站规则（[初次](context-first)、[修正](context-fixed)）。
- 七项旧夹具依赖未加载方法却隐式收到提案正文、空上下文或手写模型消息。现改为真实方法、领域投影及快照引用，保持生产守卫；额外抽取对标手写宿主也在最后 54 项中验证。
- 私有页面种子最初遗漏当前必填负责人、误用历史 Grant 字段，初始化事务整体回滚后按实际模型修正；未覆盖旧数据。预览首次访问不存在的路径后，经真实导航进入页面。
- 十二个技能版本/digest 已更新，旧 T0 资格不能自动沿用；不修改 golden-case、不授予真实资格。无业务库迁移，head 保持 `s0_0772`；测试始终为已核对 marker 的独立 `127.0.0.1:64245/pdos_test` 及同标记检查点库，无 `.env` 回退。
