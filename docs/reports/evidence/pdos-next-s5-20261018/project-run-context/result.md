- 项目驾驶舱及项目工作台把实际项目带入小Pai新工作；项目资料尚未核对时不显示可发送输入。新请求、原请求恢复按项目隔离；服务器读取实际当前项目并核对 tenant/category/product。历史无绑定保持空，不按型号推断。
- Session/Run/RunScope 固定项目；继续工作只引用原 Run，由服务器继承项目、型号、会话和来源。运行恢复与每次领域/模型端口前沿原 Store 重新核权，原 Temporal 五键引用与注册 LangGraph 路径不变。元数据仅读者可只补读缺少的范围列，不被迫读取私人正文。
- 项目动态加入本人显式绑定运行的真实 AgentEvent。只选择固定类型、事件时间/序号、绑定执行身份、请求人和受控状态；没有 goal/result/versions/完整 body。业务回执与运行事件分开，纯读取运行 receipt_id 为 null，事件序号不冒充 Run 版本。Run/Event 原本人私有 RLS 不扩大，项目其他受众不会获得私人对话。
- 相对规则的新 Run 从已确认规则的真实时间来源项目取绑定；手动、纯定时及未选项目的历史继续为空。SQL 与 Python 同时核固定关系和当前权限；0794补齐较窄 Project 的 private_context，不因型号共享而丢失分类。已开始运行、旧记录不回填。新增项目上下文只在末尾投影，冻结提示词与工具定义不插动态值；声明字段进入现有技能摘要，资格不自动继承。
