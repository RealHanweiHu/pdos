## PG 测试（权限负例为主）

`test_memory_notes_pg.py`、`test_memory_candidates_pg.py`、`test_memory_vectors_pg.py`：

- 他人不可读：同租户同事读不到、改不了、删不了本人条目；跨租户读到空列表；同事的运行既不带入本人条目，也不按本人叫法扩展检索。
- AI 不能直写：AI 写入身份向 `memory_notes`、`memory_note_versions` 插入被行级权限拒绝；以 AI 身份删除版本删不到任何行；任何人都不能改版本（无 UPDATE 权限）；AI 身份不能替本人对提议作决定；向量表 AI 身份插入被拒。
- 提议边界：冻结提示词 1.0.0 下模型提议一律拒收（`memory_candidate_prompt_not_released`）；放开版本后（只在测试里）提议不写入条目，本人点“记住”才以本人身份写入；页面资料里的“记住……”、没有“记住”说法的原话、超出本次运行范围的作用域都被拒；主动提议须两轮本人原话、每会话一次、本人可关；不进记忆与管理员关闭时不接收；运行结束后任何身份都不能再给它挂提议；别人的身份不能给本人的运行挂提议。
- 冲突：相似条目不选就保存被拒（409，附相似条目）；替换、合并、都保留各自生效，旧版本号过期被拒。
- 删除：版本正文和来源提议被清除，只留删除记录；带入了该条的运行在下一次模型调用前停下；之后的运行不再带入、检索不到；“用到了 N 条记忆”只显示“已删除”。
- 常驻注入：只带全局与本范围条目，口径/叫法进约束区、背景进背景区，≤1,000 token 且报告未带条数；个人入口只带全局条目；不进记忆零读取。
- 管理员：非管理员读计数被拒；计数不含已删除条目；计数结果不含正文；计数函数拒绝非“本人真人管理员”。
- 向量化：未勾选“本人会话记录”时派发为空、零出站；勾选后只发送本人原话，回执里服务商与类别由服务器判定（`owner_session`），私有运行的情景不发送；向量召回与关键词 RRF 融合；勾选但查询向量不可用时标“仅关键词”；别人的身份不能替本人向量化；注册执行图之外不发送。
