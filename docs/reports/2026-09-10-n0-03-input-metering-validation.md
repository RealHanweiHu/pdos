# N0-03 输入计量与资格装配验证

2026-09-10。按已冻结 DC-07 继续预算基础建设。本片交付固定资产计量、原生计数接口和受信发布资格加载，接入显式预算控制器。真实模型资格尚未发布，默认预算工厂尚未采用，N0-03 保持部分完成。

## 已实现

- 本地 tokenizer 与聊天模板按摘要固定，不执行远端 Python；去除 tokenizer 导出的 padding/truncation，计入完整文本和模板封装。
- Anthropic 计数接口与生成共用输入序列化，执行现有出口策略；限定响应大小和超时，禁止重定向/重试，严格校验整数计数。
- 发布包与模型 golden 资格按 suite/version/digest 匹配；精确绑定 provider/model/protocol/endpoint、资产、真实回执、覆盖输入上限、输出能力、余量和有效期。四类样本齐全、请求回执 ID 唯一，本地计数必须可重现，含余量计数必须覆盖观察用量。
- `ModelBudgetController.from_publication` 将发布资格接入现有逐次预留与派发；计量前后及派发前复查资格，预留后撤销会取消未派发预算。默认工厂保持原采用状态。
- 只读核验 CLI 与四次合成请求采集脚本；后者默认仅预检，真实执行须 `--execute`，不覆盖既有文件，不重试，未知用量停止。脚本不能发布资格或修改 golden。

操作、发布字段、信任边界和受限请求形态见[运行手册](../runbooks/model-input-metering.md)。新增依赖 tokenizers、Jinja2，锁文件保持 pypdf 6.15.0，无无关升级。
