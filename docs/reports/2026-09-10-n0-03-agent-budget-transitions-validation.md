# N0-03 受限预算转换接口验证

2026-09-10。继续已冻结 DC-07，新增 `0066_bound_budget_transition`，让服务端和运行租约绑定的 Agent 使用同一个模型预算状态机。N0-03 保持部分完成，默认 Agent 完整预算模式尚未启用。

## 已交付

- `transition_bound_model_budget` 为已由服务端预留、已绑定请求摘要的模型 attempt 提供 dispatch/unknown/cancel/settle。Owner `BudgetLedger.transition` 对绑定模型调用复用此函数，旧无绑定预留继续原有兼容语义。
- `RestrictedBudgetTransitions` 与权限脚本中的安全包装函数绑定真实 run lease。租户、项目、运行和 Agent 键由服务端运行记录派生；Agent 不传政策、额度或租户参数，不获预算表或业务表写权限，worker 不获此接口。
- 同租户事务锁保证 Owner 与 Agent 并发派发只有一个获准；重复派发返回原记录但不再授予调用权。转换期间共享锁定运行行，终止或换租约不能穿过检查窗口。
- 取得运行行锁后重新读取数据库时间，防止等锁期间已过绝对期限的调用仍被派发。新增并发用例观测真实 PostgreSQL Lock 等待后让预算过期，验证零派发且预留仍持有。
- 未知响应保留预留，已派发不能取消；有据结算保留实际超额用量。数据库再次验证完整回执字段、严格非负整数、缓存子项、请求摘要及类型，限制正文大小，生成正文摘要留痕。
- 运行终止或租约失效后，Agent 无权释放未知预留；Owner 服务仍可根据供应商证据对账。空历史迁移可往返，有绑定转换历史则拒绝回退，避免撤掉恢复所需函数。

接口、采用边界及 DBA 流程见[运行手册](../runbooks/agent-budget-transitions.md)。本轮没有新增表或列，没有引入新服务、凭据、模型工具或生产配置。
