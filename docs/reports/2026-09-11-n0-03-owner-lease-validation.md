# N0-03 主动请求 Owner 租约验证

2026-09-11，本地候选 0084。四个预算应用入口在创建事务内固定执行持有者，真实心跳续期、模型派发和成功发布均受原租约约束；dispatcher 已接入零模型调用的过期清理。N0-03 保持部分完成。[运行说明与剩余](../runbooks/application-owner-leases.md)。

## 交付与证据

- Chat、风险建议、测试计划和报告映射取得原授权下的 Owner 租约。工厂保存原 token，另一实例或错误 token 不能接管已有运行；不从模型参数或数据库当前值反向取得持有权。
- 真实心跳续期保留同一 token，60 秒期限不超过原授权/预算绝对截止。到期不能续期复活，正常结束固定结束时间/原因。身份字段和结束历史不可覆盖；结束时间/原因必须同时存在，含 SQL NULL 反例验证。
- 应用 Manifest 通过同租户/run 外键关联 Owner lease。Manifest 建立后、预算派发前发生到期，数据库仍拒绝发送。原 token 事务绑定缺失时，数据库拒绝新 Finding 或 run 成功状态转换。
- 风险/测试计划的实际 API 在来源记录后租约到期，返回可见不可用且零模型请求；报告映射在模型返回后到期，不生成导入批次，已发生的用量仍结算。只读与候选、人审接受/应用边界保持。
- 活动时间与租约期限同步，结束时封顶到 lease_expires_at。创建时绑定主动请求租约不会改写旧事件活动分段；单独的旧事件分段回归通过。
- dispatcher 使用 SKIP LOCKED 的确定性清理：到期请求转 degraded；已派发但回执不明的调用保留原额度占用和账本，不重置预算、不自动重发、不生成业务写入。清理重复执行幂等。
- 新增一张 cehub_ai 运行控制表和一个 Manifest 外键列，无新 namespace。Worker 只新增过期清理函数的执行权，Agent 不可调用；两种受限角色对租约表及私有有效性函数仍无直接权限。
