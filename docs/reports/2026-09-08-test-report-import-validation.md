## 运行方式

原 Python 与前端依赖存在 iCloud 占位文件，读取停顿。按锁文件在 `/private/tmp/pdos-report-venv` 和 `/private/tmp/pdos-report-web-check` 恢复依赖；前端临时副本使用当前修改/新增源码，未修改的受 Git 管理源码从 HEAD 读取以避开云盘停顿。未改项目依赖声明和锁文件。后端仍从仓库执行，数据库隔离保护使用 `configured_test_database_url()`，仅 `pdos_test`，测试准备执行 Alembic head。

聚焦后端命令：`python -m pytest tests/test_test_report_workbook.py tests/test_test_report_mapping.py tests/test_test_report_import_api.py tests/test_test_runs_api.py tests/test_npi_execution_api.py -q --tb=short -p no:cacheprovider`。

前端命令：`vitest run`、`eslint src`、`next typegen`、`tsc --noEmit`。上传路由测试使用 Node 环境，保证 Request/FormData/File 与服务器运行环境一致。

构建发现现有搜索路由额外导出内部 `forwardSearch`，违反 Next.js 路由导出要求；仅移除该多余导出，搜索接口 3 项回归和该文件 lint 重新通过，随后构建通过。没有改变搜索行为。
