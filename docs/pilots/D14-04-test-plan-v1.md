## 使用规则

在“项目工作区 → 试制·测试·质量 → 从模板创建测试计划”选择该类型与版本；填写计划名称、实际测试阶段和计划样机数量；将手电筒功能标为不适用并填写理由后保存。已有空白计划也可绑定；已有用例或已绑定模板的计划不能覆盖，换版另建计划保留历史。

保存模板不代表测试完成。仅有模板、未确认草稿、缺证据或直接点击用例“通过”均不能充当已确认的结果证据。覆盖按测试项计数，不代表全部样机均通过，也不能直接替代 Gate 验收。

原报告的型号、样机序号、日期、测量值、图片、签名与结论不复制为 D14-04 数据。实际执行时仍需项目规格书引用及本项目的样机/报告/结果。
