# N0-06 试点责任与测量设计

2026-09-10，`1.0.0-draft.1`。这是可供登记、采样与复核的设计包，未采集真实员工样本，未冻结 DC-10 的真实窗口或阈值。依赖已批准 N0-01；不采用待批准 N0-02 的运行参数，不开启任何模型、外发或生产操作。

## 1. 使用与裁决

1. 系统验收人继续为用户；由实际业务负责人在[试点登记](pilot-register.json)中填写各业务职责、受控人员映射引用及授权用途。空缺保留空缺，不能默认由用户代任。专业职责不是新增系统权限。
2. 选择场景、同口径任务对、允许的资料版本、纳入/排除条件，先登记基线窗口，再采集。真实员工办理并由下游接收才属于业务价值证据；角色模拟、历史回放与合成样例分别记录。
3. 依据[采样字段](sample-fields.json)登记每次任务及人工活动段；按[指标字典](metric-catalog.json)计算，保留原始分子、分母、缺失、排除、角色、窗口及样本量。现阶段是逻辑取数合同，未接入生产埋点或生成统计结果。
4. 基线采集完，由业务/数据职责核对，同系统验收人登记阈值版本、理由、验收窗口及最低样本量。新版本不覆盖旧记录；验收窗口开始后改阈值须有具名修订及重测范围。
5. N7-03 采实际样本和校准；各领域 N 项提供真实专业质量与接收结果；各 Q 出口按本阶段范围裁决。N0-06 的设计不替代 V0-5 的真实基线冻结或任何出口。

主要审阅顺序：里程碑兑现（保留北极星）、同类任务总主动时间变化、首次下游接收率；其余业务指标用于领域诊断，安全、必需 Gate 证据及 UX 硬线独立验收。全部原指标保留，不用三个摘要指标替代它们。

## 3. 抽样和对照协议

观察单位为一次具名业务任务包，从取得必要输入到完成执行、审核纠错并交付接收；跨人交接保留原 task/pair/attempt 关系。阶段、专业、任务类型、复杂度、来源完整度、模型/工具/流程版本、是否首次使用共同定义分层。PM 指产品经理和项目经理时使用两个独立职责标识，不能合并。

基线与辅助任务必须相近复杂度、同目标/资料可用性和验收标准。真实任务不能为试验重复产生业务提交；采用匹配但不同的任务，并记录匹配依据。离线同一材料重复办理须记录顺序/学习污染，结果仅作受控比较，不能冒充独立真实任务。能力消融按同模型/计算预算、相同授权输入和安全边界离线比较，不在生产停用安全规则。

先登记每个角色/场景的连续合格样本队列；不可只挑成功、已采纳或完成快的任务。失败、未接收、撤回、失能及超时均保留，排除需预先规则与逐项理由。未完成任务的主动投入照实计入，周期作为截至 as_of 的未完成/右删失样本另列；不能当 0 秒或从总体悄悄删去。汇总必须同时报告可配对数、未配对数、人数、任务数、缺失数和已排除数。

窗口采用明确时区、UTC 起止和 `[start,end)`；由业务事件时间纳入，迟到回填标记 observation_time 与 ingestion_time，重算新快照版本，不覆盖历史报告。同一指标基线/辅助分母按相同单位，数量加总分子分母后重算比率，不平均不等分母百分比；跨专业比较仅在可比层内进行，不能用全员均值掩盖品质或 DQE/SQE/IE 退化。

样本量/窗口/阈值目前均为 null，状态 `not_assessed`。建议先用完整连续队列判断波动与缺失，再由责任人预注册最低样本量及固定验收窗口；不编造统计把握度。报告小样本的全部明细/范围，具备足够样本后使用预注册的配对差值区间；重复同一人/项目按参与者/项目聚类，不当成独立多人样本。

## 4. 时间、质量与计数规则

总主动时间是所有参与者的准备、学习、输入、审核、纠错、追问、业务办理、交接与接收活动之和（person-seconds）。同一人的重叠区间先求并集，跨人并行时间相加；同一次追问不能同时加在输入和追问段。审核人/下游接收方投入也计入，未使用 AI 的任务不能省略对应工作。

等待模型/供应商/客户/排队等 passive 段单列 wall-seconds；端到端周期为结束减开始，不等于主动投入。首用学习既单列也计入首次完整总投入；熟练期另建分层。节省秒数=`baseline_active−assisted_active`，负值真实显示；百分比仅在基线>0且可比较时计算。缺少审核/纠错活动确认记录是缺失，不能假设为 0。

重复录入按同一来源事实在多个位置再次人工写入的次数/活动时间；复用一次来源绑定不算重复。追问按请求额外澄清的独立轮次，追问时间另记。返工必须有具体遗漏/错误原因和版本回链，正常范围变更单列。接收率按真实接收方第一轮通过计算，模型 apply 成功不等于接收。噪声由收件人标注重复、无关、过期或无可办动作，未反馈记未知，未点击不自动算噪声。

指标值有 `observed / not_applicable / incomplete / not_assessed` 四态：完整且分母>0才计算；完整但0分母为 N/A；关键字段缺失为 incomplete；未采样/无阈值不得报告验收通过。真实数值0与未知null分开。率类保留 raw numerator/denominator；超出合理范围需查错，不能截断掩盖重复计数。

## 5. 时间与供应专项防失真

北极星按最新**人工确认** Commitment 的兑现统计。按 as_of 与到期窗口选取已纳入持续预测的关键里程碑；到期未完成留在分母视为未兑现，Actual 未达记录不能填成功。完成后的承诺改写不能追认准时；另报原承诺到期 cohort、承诺变更次数/推迟天数、预测覆盖缺失和移出窗口的条目，防止不断推迟分母。旧/新承诺与批准时刻均保留。

Forecast 序列从能力落地时就追加记录，绑定 as_of、事实快照、Baseline/Commitment 版本、模型/规则版本与适用时区/工作日历。只使用预测当时已知事实；按距目标的预测跨度分层报告 Actual−Forecast 的有符号误差和绝对误差，未完成里程碑保留删失状态。历史报告回放不能倒填“提前发现”。

齐套以具体 Build 的有效需求行/数量、单位、版本及库存/供期快照为口径，关键件子集事前标记；采购单已发不算可用物料。样品承诺和实际分别留版本与时间。良率只能来自真实报告中按样机/批次定义的通过数与检测数，不能从测试项覆盖率推算。

## 6. 质量样本与发布

[golden 候选清单](golden-candidates.json)位于 docs，不写入 `server/golden/`。每个候选先取得用途授权、去标识映射、来源 digest 与预期结果的专业核对，再由人工发布不可变 suite；本包不生成虚假真实模型样本，不把历史源文件授权扩大为模型出站授权。

每能力/实际席位随所属 N 项覆盖正常、缺项、冲突、陈旧、越权、注入、工具失能、超时、取消、压缩恢复、重复应用。只读结果无需人为制造 Finding；模型业务候选必须分别计接受、修改、拒绝、独立应用与业务接收。费用未知仍为 null，不采纳待批 DC-07 作为已运行计费事实。

## 7. 当前缺项与验收分界

已提供三种试点用途、职责/场景映射、采样字段、完整指标字典及 golden 候选设计。真实业务人、数据用途细项、窗口、独立人数、最低样本量、基线/阈值、发布者及实际结果仍待运行中登记。当前不需要重新索要 D14-04 报告或重复批准 D14-02 回放；这些缺项仅阻止相关效果/阈值裁决。

N0-06 保持部分完成：本设计尚待责任人走查和 DC-10 对应测量协议/版本登记。活动清单仍以 N0-02 为主指针；本项是其等待期间的独立进展，不改变工作项数量与依赖。
