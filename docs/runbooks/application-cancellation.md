# 应用任务取消

本地候选 0091 提供 POST /api/ai/runs/{run_id}/cancel，项目运行列表显示本人活动请求的“取消任务”。Chat 原取消入口复用同一服务。服务端从运行发起人或既有应用授权记录识别本人，并复核当前登录与项目访问。操作不需要模型网关。

排队、运行中、等待补充及可恢复的租约过期请求可取消。事务持久保存操作者、原请求、预算链及时间，关闭未解决的等待，结束活动运行及租约。已关联的同链活动请求一起停止；新关联运行和原链后续预算准入会被拒绝。重复取消返回原控制回执，changed=false；已自然结束且没有活动后续的任务保持原结果。

项目列表显示“已取消”，控制按钮消失。取消不会删除调用、观察、候选或预算历史；已实际用量和未知回执的持有额度继续保留。已发布候选仍由既有独立人工审阅/应用流程处理。前端取消失败时保持当前任务状态并显示可重试信息。

当前入口面向有可信发起人的应用请求；事件 Agent 的人工控制、暂停/恢复、完整 RunControl 投影，以及其他应用队列/等待点按 N0-03 继续。取消记录和接口没有授予 Agent/Worker 直接权限。本地验证不代表生产部署或真实模型资格发布。
