# 小Pai 草稿技能试点资格

依据冻结 v1.1 §06.12、附录 A 的 `ai.skill.qualify`（T2）与确认稿 C8。适用于已登记试点租户的草稿技能；政策批准本身不授予真实租户或模型资格。

## 本人办理

在品类工作台 → 设置 → AI 运行与费用 → 案例审阅与试点资格中选择技能。当前租户管理员须有当前品类写入权限，使用本人会话办理。

1. 核对实际技能和模型版本。模型凭据、价格或 KMS 内容不进入审阅记录；页面不调用模型。
2. 亲自审阅自有或合成材料，填写材料定位、结论、错误程度与六项审阅维度。未评价项保留为未知。每批 1–20 条，一次确认保存本人私有、不可覆写的审阅记录（T1）。不要把客户资料全文粘贴到审阅结论中。
3. 选择 10–20 个不同材料的本人审阅，填写决定理由，预览后本人具名批准资格（T2）。服务器核对试点登记、技能启用、实际技能内容、相关工具和模型身份；没有另加通过率门槛。严重错误案例不能用于批准。
4. 需要停用自动写入时，具名撤销资格。即使模型配置、技能包或试点已停用，仍可撤销已有资格。原案例、具名决定和业务回执保留；撤销不自动关闭技能或删除业务事实。

试点登记是服务器维护的租户事实 `tenant_pilot_admissions`，应用账号无写权限。真实登记或撤销须由有对应明确授权的维护人员依据批准材料执行；本闭环不提供应用内自助试点准入，也不预置真实租户。

## 生效与暂停

资格绑定租户、技能包的内容和相关工具定义、服务协议类型/基础端点/模型名称/模型版本。技能内容、相关工具或实际模型变化，旧资格失效，须重新审阅。无关工具、价格调整或凭据轮换不改变质量身份；凭据和运行绑定仍受原来的安全与当前配置检查约束。

对已登记版本记录严重错误，会立即暂停该版本后续 T0，并推进技能状态版本。恢复须使用严重错误记录之后的新审阅材料，重新具名决定；同一严重错误批次中的其他案例也不能冒充重新审阅。暂停不覆盖此前事实。

运行时仍逐次核对当前授权、来源、资料出站协议、预算和原执行绑定。T0 资格只适用于登记的草稿动作，T2 正式决定永远由有权本人办理。

## 不确定结果

保存前保留原请求。刷新页面只查询本人、当前品类下同一请求的真实回执，不自动补交。原回执存在则显示相同回执；人工点击重试才重新提交原请求。权限、版本或证明已变化时重新核对，不能换请求编号盲目重试。

案例原始记录只向本人会话开放，Agent 不可直接读取或写入。具名决定与 Receipt/Audit/Outbox、实际消费的确认凭证同事务提交。迁移头 `s0_0769`；存在审阅、资格或具名证明历史时，不允许用破坏性降级抹去历史。

当前交付仅有本地合成验证；真实模型、KMS、签约与价格材料、真实资格和完整 M3/S1 验收仍需对应真实条件与授权。
