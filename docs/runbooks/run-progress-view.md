# 运行详情与累计用量

N0-03 本地运行详情接线，沿用 0095 数据结构，无新增迁移。项目 AI 运行列表的“查看运行详情”按需读取 `GET /api/ai/projects/{project_id}/runs/{run_id}`。展开的活动任务每 5 秒刷新，收起或进入终态后停止轮询；查询失败保留明确标记的旧快照，可手动重新查询。

接口复用当前账号和项目访问检查，个人请求仍限原发起人。只返回运行状态、记录数量、最近工具名、停止码和预算汇总，不返回 prompt、用户输入、观察正文或内部授权内容。阶段依据已派发/未结算的模型请求、工具派发/观察及已保存结果判断；无法确定具体步骤时显示一般运行状态。

预算按照原 lineage 汇总，同一尝试只计算最后一条账本修订。已计入 token、预留 token、可用余额分开；待返回/回执未知仍保留预留。活动时间使用与执行限制相同的数据库区间计算，按停止/租约期限封顶；等待补充不计活动时间，绝对截止时间继续有效。没有预算绑定的旧运行返回 budget=null；缺少活动历史时返回 null，不补造零。

费用为已有模型回执中确认计价或确定未调用的金额，单位换算自 micro-USD。未知价格、未完成派发或缺失费用回执标记记录不完整；不称为全部工具费用或最终账单。运行详情是状态查询，不改变原预算、租约、事件、Finding 或业务对象。

观察、模型回执、已保存结果和工具步骤分别计数，0 表示没有该类持久记录。运行完成、建议应用与业务完成继续独立展示。暂停/恢复、新输入修订及其他等待点按 N0-03 后续项接线。
