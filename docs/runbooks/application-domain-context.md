# 主动入口的领域来源与模型上下文

0084 已接续 [Owner 租约与过期清理](application-owner-leases.md)；下文保留 0083 的来源适配范围，持久等待与分步恢复仍未完成。

2026-09-11，本地候选 0083。在 0082 Chat 观察结构之上，风险建议、测试计划建议和报告映射三个预算入口保存真实来源快照，并使用同一应用 ContextManifest 准入链。

## 读取与复核

| 入口 | 实际记录 | 当前事实复核 |
| --- | --- | --- |
| 风险建议 | RunContextBuilder 返回的项目、执行摘要和触发事件；实际 concern/引用投影另存为出站收据 | 项目、业务执行指标、触发事件重新读取比较；当日调用数和剩余额度是原时点快照，自己的调用会改变这两项，不作为业务来源变化 |
| 测试计划 | 原计划及用例/结果状态、对话消息、实际选择的来源快照、上一候选载荷 | 重读计划状态和所选来源；上一候选须仍可用、未被后续候选替代且载荷相同 |
| 报告映射 | 原上传请求身份与文件 SHA-256、实际表头、发送给模型的前五行样本、解析后总行数 | 原 run 中上传请求身份须相同，所属项目和计划仍存在；用户权限另沿原授权复核 |

报告输入只保存本次映射实际使用的样本快照，不宣称已在观察表保存完整原文件或重读对象存储。超过五行时 Observation 为 partial，保留 shown_count/total_count、truncated 和未展示行的来源定位；Manifest 写明 sampled_report_rows。该定位不是已经实现的模型续读工具。测试计划与报告输入按 untrusted_external 标记。

风险和测试计划的 complete 指本次选定输入的读取完整性，不表示已覆盖项目全部知识或领域验收要求。

每次记录固定原用户授权、稳定 model_call_id、本地内容包，以及投影后的实际 prompt/instruction/schema/context。计量前、预算预留后派发前和响应后核验该合同及当前来源。响应后发现变化不披露结果、不创建新业务候选或导入批次，实际调用追踪和用量仍结算。

## 数据库约束与兼容

0083 不新增表、列、namespace 或直接角色权限。沿 0082 的不可变观察及 Manifest 表，所有有应用授权的预算模型派发现在都必须已有 Manifest。每个结构化尝试关联真实准入行、原观察和 revision；结构化修复不重读成新的历史。

新增应用 trace 触发器：有观察历史的 run 写入正次数 model_invocations 时，每个 structured_attempt 都须能沿同租户/run、budget_call_id 和实际准入 request_binding 找到 Manifest。跳过应用回调不能绕开数据库派发门禁，伪造另一 call 的 trace 也被拒绝。

已有模型调用、预算账本或调用会话却没有观察历史的 run，禁止补填新 Observation。没有观察的旧在途调用仍可保留其实际 trace/结算；不把后补快照伪装成调用前取证。默认 legacy 入口的原兼容行为保留，已绑定预算不能回退 legacy。

有非 Chat Manifest 历史时禁止降级到 0082；只有 Chat 历史可以退到 0082，但再退 0081 仍由原上下文历史保护拒绝。空库可往返迁移。Agent/Worker 没有这些表的直接读写权限，也没有调用新增触发器函数的权限。
