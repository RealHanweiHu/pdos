# 读取循环的分步恢复

本地候选 0090 为已固定资格的 bounded_tools.v1 事件 Agent 循环保存步骤检查点。每次模型选择工具、工具读取和观察记录均完成后，保存下一步编号、原上下文、已读页面、引用及模型调用记录。随后退出的进程可由现有 dispatcher 回收，新执行器从下一步继续。

恢复保留原运行、授权、版本、预算链和截止时间。已完成的模型调用、嵌入检索和观察写入不重做；恢复前仍按既有规则复核当前来源和资格。最终答案检查点优先，存在完整结果时继续沿用原有发布恢复。

检查点通过绑定运行租约的服务端窄接口保存和读取，不是模型可选工具；表保持追加且没有新增 Agent/Worker 直接访问权。恢复记录通过 loop_checkpoint_id 关联所用步骤。固定流水线和未采用循环的运行不受影响；没有自动启用真实模型资格或循环模式。

只有完整步骤可接续。如果已有下一次模型调用而尚未保存对应步骤/最终结果，则记录 AGENT_LOOP_CHECKPOINT_INCOMPLETE 并停止，避免重发。未决模型或工具回执继续采用原停止规则，预算和最大步骤数不重置。

运行方式沿用现有 Agent dispatcher/executor。无需新增队列进程或环境变量。其他应用能力的分步执行、等待点和完整 RunControl 仍在 N0-03 后续范围。
