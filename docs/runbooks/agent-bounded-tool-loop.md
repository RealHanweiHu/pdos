# 事件Agent有界工具循环

2026-09-11，N0-03，本地候选migration `0078_event_loop_binding`。现有事件执行器已具备“模型选择工具→真实只读handler→持久Observation→模型继续→最终评估”的循环。默认仍为固定读取图；本片没有发布真实循环用途资格或启用生产。

## 执行与范围

循环复用原初始项目/事件/知识及适用的领域证据读取。每轮模型只返回一个结构化动作：`tool`或`final`，不存储私有推理链。工具请求来自封闭schema：项目快照、近期事件、知识查询、工程/质量/供方/Portfolio摘要。必须同时属于当前Agent原有工具集合；未知工具、其他专业工具、租户/项目字段及错误cursor组合拒绝。

模型不传project_id/tenant_id，服务端从冻结run注入。循环提示词及工具定义在每轮保持相同，动态step/剩余轮数、实际工具请求与观察放到上下文末端；未接线的Reach工具不在此循环提示词中出现。外网读取、业务写、Finding直接应用和新领域载荷不因循环获得权限。

模型每轮经过原Gateway、出站投影、输入计量、原预算准入、trace及已冻结ContextReceipt验证；每个step使用run派生的固定model_call_id。模型选择的工具沿0077先登记、再提交唯一派发许可、最后执行并写Observation，不能绕过原次数或租约。新观察按顺序关联到下一次ContextReceipt，实际引用累积进入下一轮。

最终评估才进入原Finding预检和独立人工接受/应用。最后允许的模型step仍要求读取工具时，返回明确`AGENT_LOOP_MODEL_LIMIT`并停止，不为没有后续推理机会的请求再派发工具。结构化修复及其他模型尝试仍独立计入原硬限，可能更早终止。工具异常记录固定失败观察后停止，错误清理不调用模型。

事件after_id及知识/专业工具offset都直接进入实际handler。对offset工具，Observation数量描述从本次offset开始的剩余窗口，shown_count仅计本次返回的行，不能把跳过的行算成已展示；完整ToolPage正文仍保留原总量。缺少知识数据源时显示unavailable/未知数量，模型不能把它当成空的verified事实。

## 创建时绑定与显式采用

两个新增配置默认留空：`PDOS_AGENT_LOOP_QUALIFICATION_PATH`和`PDOS_AGENT_LOOP_QUALIFICATION_SHA256`。dispatcher与executor必须读取同一份可访问的操作者发布件，并同时采用已有budgeted模式/profile；单独路径、错误摘要、失败状态或不匹配的运行源码摘要会拒绝装配。Compose已传递这两个可选值，路径所指文件的只读供应仍属于部署准备。

发布件包含版本、passed状态、运行源码/提示词摘要、provider/model、用途suite版本/摘要、证据引用及批准人。装载器只验证操作者发布件的形状、独立摘要及当前运行匹配，不执行评测，也不以自报passed代替实际用途评测。真实suite、评测证据和操作者批准必须另行具备；既有通用模型资格和输入计量发布包继续独立必需。测试中的synthetic发布件不能用于真实环境。

dispatcher在新事件run的创建事务设置服务端策略；数据库把`loop_binding`冻结到新run，并要求同时有事件预算配置。已有绑定不可修改，不能给旧run补新模式或重新分配额度。执行器通过当前lease只读端口读取并核对相同发布件及源码摘要；缺失/变化则在工具前拒绝。没有loop_binding的旧固定流程仍按原模式执行，即使进程已配置循环。该可空字段以SQL NULL表示未绑定，避免JSON null被误当作显式策略。

循环每次模型调用都核对发布件固定的provider/model，当前租户选择变化后不向另一个模型继续派发。通用模型失能、预算、租约、触发期限和capability rollout检查继续生效。本片源码摘要约束循环相关实现/提示词及部分依赖，不宣称已完成完整部署版本束、授权Envelope或全部领域用途资格绑定。

## 持久化与恢复

结果checkpoint新增本次循环额外读取的参数和真实返回值，原初始页保持独立。恢复先复查原上下文、事件/领域页，再逐个复核额外的非知识读取。所有实际消费的知识行（含额外末页）按当前受限投影复查ID、正文及版本；撤销知识验证会停止发布。恢复不重复嵌入查询、模型调用或工具派发。

只有最终模型结果形成当前结果checkpoint。中途工具回执未知或缺最终checkpoint仍沿0073～0077停止处理，不重新开始整个循环。逐步恢复、等待人输入和中途checkpoint继续建设，不能把已记录的工具意图当作这些功能已经完成。

0078只增加可空绑定列、创建时冻结触发器和受限只读绑定端口。Agent/Worker不获得业务表写权限。空绑定历史可降回0077；有绑定历史拒绝降级。DBA模板仍在全部定义后统一COMMIT，撤销脚本删除公开读取端口并保留历史。
