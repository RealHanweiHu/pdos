# 停止项目事件任务

本地候选 0095。项目 AI 运行列表现在对有项目编辑权限的用户开放事件任务的“取消任务”。Owner/Admin 或有当前项目访问权的 Project Manager 可以停止合并等待、排队或运行中的事件任务；个人请求仍只由原发起人取消。

复用 `POST /api/ai/runs/{run_id}/cancel` 和既有回执结构。服务端根据可信 run 字段区分个人请求与项目事件，复查当前账号、会话版本和项目编辑权限。查询接口返回 can_cancel 和 cancelled 状态，无需客户端猜测权限或事件类型。

取消记录保存在既有 `application_cancellations`，这是 Owner 应用写入的人工控制回执，也用于项目事件。数据库以同一预算锁停止本项目同一 lineage 的活动事件任务；拒绝混合个人请求或其他项目。原累计预算、模型费用、在途未知预留、观察和检查点保留，后续调用与结果发布受既有 lease/预算约束拒绝。错误清理不调用模型。

内部历史兼容为 failed + EVENT_RUN_CANCELLED，对外展示 cancelled。未开始的任务保持 started_at 为空；运行中的活动计时结束。重复取消返回 changed=false，已经完成的任务和 Finding 保留。

取消针对该运行及其预算链，不关闭订阅。真实的新业务事件可以触发新任务；已停止的旧任务不因 worker 恢复而重新执行。永久停用能力继续走原治理路径。

需要先迁移至 0095。没有为 pdos_agent/pdos_worker 添加取消函数或控制表写权限；HTTP 控制由 Owner 应用连接执行。本说明不授权生产部署。暂停/恢复、新输入修订和完整 RunControl 可视化继续按 N0-03 原计划交付。
