CEHub V3.2 Engineering Baseline
Architecture:
AI Native Manufacturing Product Development Operating System.
Boundary:
CEHub manages product development context, collaboration, decisions and AI intelligence.
It does not replace ERP, MES, PLM, CAD.
Core lifecycle:
Idea -> Requirement -> Development Case -> Project -> NPI -> MP/Ramp -> Quality Feedback -> Memory
Technology:
Frontend: React + TypeScript
Backend: API Services
Database: PostgreSQL + pgvector
AI: LLM Gateway + LangGraph + RAG
Storage: Object Storage
